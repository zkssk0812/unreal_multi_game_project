「털어라! 금고!」 클라이언트 시험용 빌드 (2026-11-17)
======================================================

정호님, 언리얼 엔진 없이 바로 실행해서 서버에 붙여 보실 수 있는 클라이언트입니다.
Windows 64비트용이고, 시험하기 편하도록 Development 구성(콘솔·로그 사용 가능)으로 만들었습니다.


1. 실행 방법
------------
 1) zip 파일을 아무 폴더에나 풉니다. (zip 안에서 바로 실행하면 안 됩니다.)
 2) 푼 폴더의 VaultHeist.exe 를 실행합니다.
      창 제목에 "털어라! 금고! (시험용 빌드)" 가 보이면 정상입니다.
      (MCPTest\Binaries\Win64\MCPTest.exe 가 실제 게임 파일이고, VaultHeist.exe 는 그것을 켜 주는 실행 파일입니다.)
 3) Windows가 막는 창이 뜨면 아래 "6. Windows가 실행을 막거나 창을 띄울 때"를 봐 주세요.


2. 서버에 접속하기
------------------
 1) 메인화면 아래쪽 주소칸에 서버 주소를 입력합니다. (처음에는 127.0.0.1:9000 이 들어 있습니다.)
      같은 PC에서 서버를 켰으면   127.0.0.1:9000
      다른 PC의 서버면            그 PC의 IP:9000   (예: 192.168.0.10:9000)
 2) 주소칸 오른쪽의 [실서버로 전환] 버튼을 누릅니다.
      주소칸 위 글자가 "접속 대상: 실서버 TCP 127.0.0.1:9000" 으로 바뀌면 됩니다.
      (처음 글자 "접속 대상: Mock 서버(가짜 서버)" 는 서버 없이 화면만 볼 때 쓰는 모드입니다.)
 3) [시작하기] → 이름 입력(영문자만 2~12자) → [확인]
 4) 로비에서 [방 만들기] → [만들기] → 대기실에서 캐릭터 1명과 퍽 3개를 고르고 [준비]
      방 안의 모두가 준비하면 시작됩니다. 혼자여도 시작됩니다.
 5) 5분 뒤 결과창 → [로비로] 또는 15초 뒤 로비로 돌아갑니다.
 6) 끝낼 때는 메인화면의 [종료] 또는 Alt+F4 입니다.


3. 맞는 서버 조건
-----------------
- 프로토콜 v3.0 (메인화면 주소칸 위에 "클라 프로토콜 v3.0 (0x00030000)" 이 보입니다)
- 서버 저장소 feature/pvpve-v3 브랜치, 커밋 1b53272 기준
- 서버 창 첫 줄이 아래처럼 맵 버전 2 이면 이 클라와 맞습니다.
    [Map] mansion_1f v2: 방 35(금고·아이템을 놓는 방 31), ...
- 서버 맵 버전이 2가 아니면 게임에 들어갈 때
  "서버 맵 버전(N)이 클라 배치(2)와 다릅니다" 경고가 뜹니다. (금고·상자 위치가 벽과 어긋날 수 있습니다.)
- 서버 버전이 다르면 로그인할 때 "게임 버전이 서버와 다릅니다" 안내가 뜹니다.


4. 조작키
---------
  WASD        이동 (화면 방향 고정: W = 화면 위)
  마우스 커서  시선·공격·스킬 방향 (투척 무기는 커서가 가리키는 바닥)
  좌클릭       꾹 누르고 있으면 계속 공격
  Shift       달리기          Space      구르기 (구르는 동안 잠깐 무적)
  마우스 휠    무기1 ↔ 무기2 교체
  F           상호작용 — 아이템은 바로 줍기, 금고·상자는 한 번 누르면 다가가서 작업
              (작업 중 이동·공격·구르기·F 다시 누르기로 취소)
  Q           캐릭터 스킬 (도적1 테이저 · 도적2 끈끈이 · 도적3 은신)
  E           소비 아이템 사용
  반납        반납지점 범위에 들어가면 자동
  `           콘솔 (숫자 1 왼쪽 키)


5. 이번 버전에서 바뀐 것 (11-16 빌드 대비)
-------------------------------------------
- 무기 10종 모양: 삼단봉·검·빔소드·권총·화염방사기·레일건·테이저·수류탄·폭발 지뢰·감전 지뢰.
  바닥에 떨어진 모습과 HUD 무기 칸 아이콘도 같은 디자인입니다.
- 손에 든 자세: 무기마다 쥐는 손·높이가 다르고, 다른 플레이어도 같은 자세로 보입니다.
- 사용 동작: 휘두르기·총 반동·레일건 버티기·던지기·설치 동작 (서버 공격 이벤트에 맞춰 재생, 다른 플레이어도 같음).
- 이펙트: 총구 불꽃·탄 궤적, 화염, 레일건 빔, 수류탄·지뢰 폭발, 감전 번개, 연막, 섬광, 맞았을 때 표시.
- 소비 아이템 4종(회복 키트·연막탄·섬광탄·1회용 제트팩): 종류마다 모양과 색 띠가 달라
  바닥에서 구분되고, HUD 소비 칸 아이콘·바닥 정보창도 같은 그림입니다.
  같은 종류를 이미 들고 있으면 줍지 않고 "이미 연막탄을 들고 있습니다" 안내가 뜹니다.
- 구르기: 앞구르기 한 바퀴 동작(0.5초). 구르는 동안 무기는 숨겼다가 다시 쥡니다.
- 쓰러짐 창: "반납한 돈 손실 -$X (반납한 돈의 10%/40%)" 와
  "들고 있던 것: 보물 $X + 환금 아이템 N개를 쓰러진 자리에 떨어뜨렸습니다"(플레이어에게) /
  "보물 $X은 쓰러진 자리에 떨어졌고, 환금 아이템 N개는 사라졌습니다"(경비원에게) 로 나눠 보여 줍니다.
  떨어뜨린 보물은 미니맵에 보라색 ◇로 표시되고, 리스폰 뒤 8초 동안 그쪽 방향 화살표가 뜹니다.
  (다른 플레이어가 주우면 사라지고 "OO이(가) 내가 떨어뜨린 보물을 주웠습니다" 알림이 뜹니다.)
- 창 제목·실행 파일 이름: "털어라! 금고!" / VaultHeist.exe (예전 "Third Person Game Template", MCPTest.exe)
※ 규칙 판정은 모두 서버 값 그대로이고, 클라는 표시만 바꿨습니다.


6. Windows가 실행을 막거나 창을 띄울 때
---------------------------------------
이 실행 파일은 서명이 없는 개발용이라 Windows가 막을 수 있습니다.

(가) "Windows의 PC 보호" 파란 창 (SmartScreen)
     → 창 안의 [추가 정보] 글자를 누르면 아래에 [실행] 버튼이 나옵니다. [실행]을 누릅니다.
     → 또는 압축을 풀기 전에 zip 파일을 우클릭 → 속성 → 아래쪽 "차단 해제" 체크 → 확인 →
       그다음에 압축을 풉니다. (이미 풀었다면 지우고 다시 풀어 주세요.)

(나) "Windows 보안 — 이 앱에 액세스하도록 허용하시겠습니까?" (방화벽, 앱 이름 "VaultHeist")
     [허용]을 눌러 주세요.
     언리얼 Development 빌드가 여는 개발용 포트 때문에 뜨는 창이고,
     게임 접속은 서버로 나가는 연결(TCP 9000)이라 [취소]를 눌러도 접속에는 지장이 없습니다.

(다) "스마트 앱 컨트롤이 이 앱을 차단했습니다" (Windows 11, 실행 버튼이 없음)
     Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정에서 끄거나,
     스마트 앱 컨트롤이 꺼진 다른 PC에서 실행해 주세요. (한 번 끄면 다시 켜기 어려울 수 있습니다.)

(라) "VCRUNTIME140.dll 이 없습니다" 같은 오류
     푼 폴더\Engine\Extras\Redist\en-us\vc_redist.x64.exe 를 한 번 실행해 주세요.


7. 시험할 때 쓸 만한 것
-----------------------
- 창 모드:              VaultHeist.exe -windowed -ResX=1280 -ResY=720
- 주소를 실행 옵션으로:  VaultHeist.exe -VHServer=127.0.0.1:9000
- 혼자서 여러 명을 붙여 볼 때 시험용 봇(자동 로그인 → 방 찾기/만들기 → 준비):
      VaultHeist.exe -windowed -ResX=640 -ResY=360 -VHServer=127.0.0.1:9000 -VHBot=Alice -VHBotMin=2
    -VHBot=이름(영문자만)   -VHBotMin=방 인원이 이만큼 모이면 준비
    -VHBotHeist(금고→보물→반납 반복)   -VHBotLoot(아이템·상자)   -VHBotHunt(다른 플레이어 공격)
  ※ 한 PC에서 3개 이상 띄우면 그래픽 메모리가 모자라 일부가 매우 느려집니다.
- 콘솔 명령 예:  vh.UseServer 127.0.0.1:9000   /   vh.UseMock
- 로그 파일: 푼 폴더\MCPTest\Saved\Logs\MCPTest.log
    "LogVHNet", "LogVHServerGame" 줄에 주고받은 패킷과 엔티티 위치가 남습니다.


문제가 있으면 로그 파일(MCPTest.log)과 함께 알려 주세요. 감사합니다.
