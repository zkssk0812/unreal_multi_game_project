「털어라! 금고!」 클라이언트 시험용 빌드 (2026-11-20 — 무기 10종 연출 개편)
=====================================================================

정호님, 언리얼 엔진 없이 바로 실행해서 서버에 붙여 보실 수 있는 클라이언트입니다.
11-18에 보내드린 버전을 대신하는 최신 버전입니다. 예전 폴더·zip은 지우셔도 됩니다.
Windows 64비트용이고, 시험하기 편하도록 Development 구성(콘솔·로그 사용 가능)으로 만들었습니다.


1. 실행 방법
------------
 1) zip 파일을 아무 폴더에나 풉니다. (zip 안에서 바로 실행하면 안 됩니다.)
 2) 푼 폴더의 VaultHeist.exe 를 실행합니다.
      창 제목에 "털어라! 금고! (시험용 빌드)" 가 보이면 정상입니다.
      (MCPTest\Binaries\Win64\MCPTest.exe 가 실제 게임 파일이고, VaultHeist.exe 는 그것을 켜 주는 실행 파일입니다.)
 3) 언리얼 엔진은 설치하지 않으셔도 됩니다. 게임에 필요한 파일은 모두 폴더 안에 들어 있습니다.
 4) 실행할 때 "VCRUNTIME140.dll 이 없습니다", "MSVCP140.dll", "DirectX", "D3D12" 같은 오류가 뜨면
    아래 필수 구성 요소 설치 파일을 먼저 한 번 실행한 뒤 다시 VaultHeist.exe 를 실행해 주세요.
      푼 폴더\Engine\Extras\Redist\en-us\vc_redist.x64.exe
    (Visual C++ 런타임을 설치합니다. 관리자 권한을 물으면 [예]를 눌러 주세요.
     DirectX 12는 Windows 10·11에 기본으로 들어 있으니, 그래도 DirectX 오류가 나면 그래픽 드라이버를 최신으로 업데이트해 주세요.)
 5) Windows가 막는 창이 뜨면 아래 "6. Windows가 실행을 막거나 창을 띄울 때"를 봐 주세요.


2. 서버에 접속하기
------------------
 1) 메인화면 아래쪽 주소칸에 서버 주소를 입력합니다. (처음에는 127.0.0.1:9000 이 들어 있습니다.)
      같은 PC에서 서버를 켰으면   127.0.0.1:9000
      다른 PC의 서버면            그 PC의 IP:9000   (예: 192.168.0.10:9000)
 2) 주소칸 오른쪽의 [실서버로 전환] 버튼을 누릅니다.
      주소칸 위 글자가 "접속 대상: 실서버 TCP 127.0.0.1:9000" 으로 바뀌면 됩니다.
      (처음 글자 "접속 대상: Mock 서버(가짜 서버)" 는 서버 없이 화면만 볼 때 쓰는 모드입니다.)
 3) [시작하기] → 이름 입력(영문자만 2~12자) → [확인]
 4) 로비에서 [방 만들기] → [만들기] → 대기실에서 캐릭터 1명과 퍽 3개를 고르고 [준비]
      방 안의 모두가 준비하면 시작됩니다. 혼자여도 시작됩니다.
 5) 5분 뒤 결과창 → [로비로] 또는 15초 뒤 로비로 돌아갑니다.
 6) 끝낼 때는 메인화면의 [종료] 또는 Alt+F4 입니다.


3. 맞는 서버 조건
-----------------
- 프로토콜 v3.0 (메인화면 주소칸 위에 "클라 프로토콜 v3.0 (0x00030000)" 이 보입니다)
- 서버 저장소 feature/pvpve-v3 브랜치, 커밋 1b53272 기준
- 서버 창 첫 줄이 아래처럼 맵 버전 2 이면 이 클라와 맞습니다.
    [Map] mansion_1f v2: 방 35(금고·아이템을 놓는 방 31), ...
- 서버 맵 버전이 2가 아니면(예: v10) 게임에 들어갈 때
  "서버 맵 버전(N)이 클라 배치(2)와 다릅니다" 경고가 뜹니다. (금고·상자 위치가 벽과 어긋날 수 있습니다.)
- 서버 버전이 다르면 로그인할 때 "게임 버전이 서버와 다릅니다" 안내가 뜹니다.


4. 조작키
---------
  WASD        이동 (화면 방향 고정: W = 화면 위)
  마우스 커서  시선·공격·스킬 방향 (투척 무기는 커서가 가리키는 바닥)
  좌클릭       꾹 누르고 있으면 계속 공격 (화염방사기는 누르는 동안 불꽃)
  Shift       달리기          Space      구르기 (구르는 동안 잠깐 무적)
  마우스 휠    무기1 ↔ 무기2 교체
  F           상호작용 — 아이템은 바로 줍기, 금고·상자는 한 번 누르면 다가가서 작업
              (작업 중 이동·공격·구르기·F 다시 누르기로 취소)
  Q           캐릭터 스킬 (도적1 테이저 · 도적2 끈끈이 · 도적3 은신)
  E           소비 아이템 사용
  반납        반납지점 범위에 들어가면 자동
  `           콘솔 (숫자 1 왼쪽 키)


5. 이번 버전에서 바뀐 것 (11-18 버전 대비)
-------------------------------------------
[무기 10종 동작·소리·이펙트 개편]
- 무기마다 공격 동작·소리·이펙트가 확실히 다르게 바뀌었습니다.
    삼단봉   : 새 동작 — 오른쪽 어깨 위로 들었다가 사선으로 짧게 내려치기, "휙" + 둔탁한 "퍽", 흰 궤적·먼지
    도검     : 수평 베기, 칼 뽑는 쇳소리, 은빛·빨강 궤적과 금속 불꽃
    빔 소드  : 크게 감았다 넓게 베기, 들고 있으면 "웅—", 분홍 플라스마 궤적·잔상·그을음
    권총     : 짧은 반동, 총성, 총구 섬광·탄 궤적
    화염방사기: 시작·계속·끝 소리
    레일건   : 큰 반동과 1초 버팀 자세, "쾅" + 방전음, 굵은 빔·충격파 링
    테이저건 : 짧은 반동, "치직", 지그재그 번개와 맞은 사람 몸 전기(경직 2초)
    수류탄   : 핀 "딸깍", 날아가는 소리, 폭발 충격파·섬광
    폭발 지뢰: "철컥" 설치, 감지되면 빨강 깜빡임 + "삑삑삑", 폭발
    감전 지뢰: 작동 중 웅웅·푸른 불꽃, 터지면 번개 여러 갈래
  이펙트 크기는 서버 판정 범위(부채꼴 각도·사거리·폭발 반지름)와 같게 그렸습니다.
- 총 든 채 이동하는 동작: 권총·테이저건을 든 채 걷기·달리기, 화염방사기·레일건(긴 총)을 든 채 걷기·달리기가 따로 있습니다.
- 소리가 멀게 들리던 문제 수정: 소리 거리를 위쪽 카메라가 아니라 내 캐릭터 기준으로 계산합니다.

[11-20 추가 개선]
- 화염방사기 불꽃: 흰·노랑 심지 → 주황 → 빨강 끝으로 색이 바뀌고, 작은 불씨가 흩어지고, 끝에서 옅은 연기와 열기 일렁임.
  판정 원뿔(600cm, 좌우 15°) 안에서만 보이게 했습니다.
- 수류탄: 손에 든 것과 날아가는 것이 너무 커 보여서 줄였고(약 0.6배), 던지기 동작을 "핀 뽑기 → 뒤로 젖히기 → 던지기"로 바꿨습니다.
  손을 떠나는 순간에 날아가는 소리가 납니다.
- 레일건: 방전음 "위이잉"이 1초 동안 점점 낮아집니다.

※ 규칙 판정은 모두 서버 값 그대로이고, 클라는 표시만 바꿨습니다.
※ 효과음 일부와 총 든 이동 동작은 에픽게임즈 샘플(Lyra Starter Game, Pistol and Rifle Locomotion)에서 가져왔습니다
  (언리얼 엔진 프로젝트에서 쓸 수 있는 에픽/Fab 라이선스). 나머지 효과음은 CC0 무료 효과음입니다.


6. Windows가 실행을 막거나 창을 띄울 때
---------------------------------------
이 실행 파일은 서명이 없는 개발용이라 Windows가 막을 수 있습니다.

(가) "Windows의 PC 보호" 파란 창 (SmartScreen)
     → 창 안의 [추가 정보] 글자를 누르면 아래에 [실행] 버튼이 나옵니다. [실행]을 누릅니다.
     → 또는 압축을 풀기 전에 zip 파일을 우클릭 → 속성 → 아래쪽 "차단 해제" 체크 → 확인 →
       그다음에 압축을 풉니다. (이미 풀었다면 지우고 다시 풀어 주세요.)

(나) "Windows 보안 — 이 앱에 액세스하도록 허용하시겠습니까?" (방화벽, 앱 이름 "VaultHeist")
     [허용]을 눌러 주세요.
     게임 접속은 서버로 나가는 연결(TCP 9000)이라 [취소]를 눌러도 접속에는 지장이 없습니다.

(다) 스마트 앱 컨트롤 때문에 실행이 막힐 때 ("스마트 앱 컨트롤이 이 앱을 차단했습니다", 실행 버튼이 없음)
     Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정에서 켜져 있는지 확인해 주세요.
     (켜져 있으면 서명 없는 실행 파일을 막습니다. 한 번 끄면 다시 켜기 어려울 수 있으니,
      어려우시면 스마트 앱 컨트롤이 꺼진 다른 PC에서 실행해 주셔도 됩니다.)

(라) VCRUNTIME·DirectX 오류 → 위 1-4)의 vc_redist.x64.exe 를 먼저 실행해 주세요.


7. 시험할 때 쓸 만한 것
-----------------------
- 창 모드:              VaultHeist.exe -windowed -ResX=1280 -ResY=720
- 주소를 실행 옵션으로:  VaultHeist.exe -VHServer=127.0.0.1:9000
- 혼자서 여러 명을 붙여 볼 때 시험용 봇(자동 로그인 → 방 찾기/만들기 → 준비):
      VaultHeist.exe -windowed -ResX=640 -ResY=360 -VHServer=127.0.0.1:9000 -VHBot=Alice -VHBotMin=2
    -VHBot=이름(영문자만)   -VHBotMin=방 인원이 이만큼 모이면 준비
    -VHBotHeist(금고→보물→반납 반복)   -VHBotLoot(아이템·상자)   -VHBotHunt(다른 플레이어 공격)
  ※ 한 PC에서 3개 이상 띄우면 그래픽 메모리가 모자라 일부가 매우 느려집니다.
- 콘솔 명령 예:  vh.UseServer 127.0.0.1:9000   /   vh.UseMock
- 게임 안에서 무기 연출만 보기(콘솔):  vh.WeaponTest 1 ~ vh.WeaponTest 10   (앞에 허수아비가 생기고 그 무기로 공격, 판정 없음)
                                      vh.WeaponTest off  (끄기)
- 로그 파일: 푼 폴더\MCPTest\Saved\Logs\MCPTest.log
    "LogVHNet", "LogVHServerGame" 줄에 주고받은 패킷과 엔티티 위치가 남습니다.


플레이해 보시고 이상한 점이 있으면 로그 파일(MCPTest\Saved\Logs\MCPTest.log)과 함께 알려 주세요. 감사합니다.
