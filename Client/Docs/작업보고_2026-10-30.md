# 작업보고 2026-10-30 — 교수님 피드백: 맵 밝기 · 손전등 몸 그림자 · 손전등 주변 빛

## 요약
- **맵 밝기**: 달빛을 0.12 → **0.8 lux**(사용자 선택 B), 각도를 -55° → **-78°**(거의 위)로 바꿨다. 손전등 없이도 방·벽·복도가 보이고, 손전등 빛은 여전히 확실히 더 밝다.
- **몸 그림자**: 의적(내 캐릭터·더미·다른 의적 표시)의 메시만 그림자를 만들지 않게 했다. 벽·가구 그림자는 그대로라 손전등이 벽을 뚫지 않는다.
- **손전등 주변 빛**: 손전등을 켜면 의적 머리 위에 약한 빛(바닥 반경 약 1m)이 켜지고, 끄면 같이 꺼진다. 다른 의적은 서버가 보내는 `ES_FLASHLIGHT` 상태를 따라 켜진다. 판정(테두리·상호작용)에는 영향이 없다.
- 수치는 모두 데이터 에셋(`DA_VHGameplayConfig`, `DA_VHInteractionConfig`)에 있고, 플레이 중 콘솔 명령 `VHMapLight` / `VHFlashPower` / `VHAura`로 바로 바꿔 볼 수 있다.

## 맵 밝기를 올린 방법 (선택 이유)
| 방법 | 판단 |
|---|---|
| 노출(자동 노출) 올리기 | ✗ 화면 전체가 같이 밝아져 손전등 빛도 묻힘 (손전등이 핵심이라 제외) |
| 스카이라이트 | ✗ 이 레벨엔 하늘이 없어 스카이라이트가 비출 빛이 없음 |
| **달빛(Directional Light) 밝기 + 각도** | ✓ 노출은 고정 그대로 → 손전등 밝기는 안 변하고 바닥·벽만 어둑하게 보임 |

- 비스듬한 달빛(-55°)은 벽 옆에 2m 넘는 새까만 그림자를 만들어 밝기를 올려도 그 부분이 안 보였다 → **-78°**로 세워 벽 그림자를 짧게 했다.
- 밝기 비교(맵 탑뷰 화면 가운데 평균 밝기): 작업 전 5.7 / A 0.3 lux 9.4 / **B 0.8 lux 23.6** / C 2.0 lux 46.4 → 사용자가 **B** 선택.

## 남은 문제
1. **다른 의적의 손전등 원뿔(빛줄기)은 아직 안 그린다.** 이번에는 요청대로 주변 빛만 넣었다. 서버가 켜짐 상태와 바라보는 방향(yaw)을 보내므로 원뿔도 그릴 수 있다.
2. 의적 몸 그림자를 끈 것은 **모든 빛**에 적용된다(달빛 그림자도 없음). 손전등에만 따로 끄는 기능이 엔진에 없어서 이렇게 했다. 경비원은 그림자가 그대로 있다.
3. `L_InteractionTest`(테스트 레벨)는 그대로 어둡다. 맵 밝기는 `VH Level View Settings` 액터가 있는 레벨(`L_Mansion_1F`)에만 적용된다.
4. 에디터 하단에 "1개 저장되지 않음"이 떠 있었다. 이번에 바꾼 에셋 4개는 모두 저장됐고 디스크에도 다른 변경이 없어, 무엇인지 몰라 저장하지 않았다.
5. 비교 사진 중 "방 12 금고 앞 (후)"는 주변 빛을 최종값(3)으로 바꾸기 전에 찍은 것이다(밝기 비교용).
6. 실서버에서 경비원이 강해 판이 빨리 끝난다(기존 문제).

## 발표 대비 메모
- **왜 노출이 아니라 달빛을 올렸나**: 노출을 올리면 카메라가 화면 전체를 밝게 찍어 손전등 빛까지 같이 밝아진다. 노출은 고정해 두고 "환경 빛(달빛)"만 올리면, 손전등이 비춘 곳은 여전히 확실히 더 밝다. → "어둑하지만 구조는 보이는" 화면.
- **각도를 세운 이유**: 해가 낮으면 그림자가 길어지듯, 비스듬한 달빛은 벽 옆에 긴 그림자를 만든다. 거의 위에서 비추면 그림자가 짧아져 방 구조가 드러난다.
- **몸 그림자만 끄기**: 그림자는 "빛"이 아니라 "물체" 쪽 설정(Cast Shadow)으로 끌 수 있다. 의적 메시만 끄고 벽은 켜 두면, 손전등은 여전히 벽에 막히고 내 몸 그림자만 사라진다.
- **주변 빛은 판정과 분리**: 테두리·상호작용 판정은 손전등 원뿔 계산(`IsBoxLit`)만 쓴다. 주변 빛은 화면에 보이기만 하는 별도 조명이라 게임 규칙에 영향이 없다.
- **다른 플레이어 손전등**: 서버가 스냅샷마다 상태 비트(`ES_FLASHLIGHT`)를 보내므로, 클라이언트는 그 비트를 보고 다른 의적의 주변 빛을 켜고 끈다. 서버가 판정의 기준이고 클라이언트는 보여 주기만 한다.
- **수치는 데이터 에셋 + 콘솔 명령**: 코드를 다시 빌드하지 않고도 기획자가 에셋에서 숫자만 바꿀 수 있고, 플레이 중에는 콘솔로 즉시 시험해 본다.

# 추가 (같은 날): 다른 의적의 손전등 원뿔 표시

## 요약
- 실서버에서 다른 의적(표시용 액터 `AVHNetProxy`)이 손전등을 켜면 **내 손전등과 같은 원뿔**이 보인다.
- 방향은 서버가 보내는 그 의적의 시선 yaw(`EntitySnapshot.yaw` = 마우스 방향)를 따른다. 원뿔이 몸(루트)에 붙어 있고, 몸이 스냅샷 yaw로 돈다.
- 켜짐·꺼짐은 서버 상태 비트 `ES_FLASHLIGHT`를 따른다. 숨음·탈출·이탈이면 끈다.
- **보이기만 한다.** 일반 스포트라이트(`USpotLightComponent`)라 내 판정 함수(`UVHFlashlightComponent::IsBoxLit`)와 관계없다. 테두리·상호작용은 내 손전등 빛만 본다.
- 벽에 막히게 그림자는 계산한다. 의적 몸은 그림자를 만들지 않는다(앞 작업의 `bThiefCastsShadow = false`).

## 개발용 명령 (게임 중 콘솔 `` ` ``, `VHHelp`로 전체 목록)
| 명령 | 하는 일 |
|---|---|
| `VHMapLight 1.0` | 맵 달빛 밝기(lux) 바로 바꾸기 (지금 0.8, 저장 안 됨) |
| `VHFlashPower 80` | 모든 손전등 밝기(칸델라, 다른 의적 원뿔 포함) (지금 60) |
| `VHAura 3 [반경cm]` | 손전등 주변 빛 밝기·반경 (지금 3, 100cm) |
| `VHOtherLights 0` / `1` | 다른 의적 원뿔·주변 빛 숨기기 / 보이기 (프레임 비교용) |
| `VHFps 5` | 5초 평균 FPS·가장 느린 프레임 (로그 `[Fps]`) |
| `VHFlashlight` | 내 손전등 켜기/끄기 (R 키와 같음) |
| `VHGoto 이름` / `VHUse 이름 초` | 오브젝트 앞으로 이동 / 가서 상호작용 키 N초 (예: `VHUse Jail 5.5`) |
| `VHJailDummy`, `VHJailSelf`, `VHSpawnDummy`, `VHDummyUse 이름 초`, `VHReleaseAll` | 창고 감금·구출 시험 (Mock·혼자 테스트 전용) |
| `VHOpenExit`, `VHGoto Floor_Exit` | 탈출구 열기 / 탈출 구역으로 이동 |
| `vh.UseServer 127.0.0.1:9000` / `vh.UseMock` | 메뉴에서 실서버 / 가짜 서버 전환 |

## 남은 문제 (모아 보기)
1. **2번 경비원 시작 위치**(`guard_spawn_2`, 문 없는 방 Room_20/L2): 잡히면 창고로 못 옮겨짐. 우리가 고칠지 정호님께 맡길지 **사용자 결정 대기**(10-28부터).
2. 경비원이 강해 실서버 판이 1분 안에 끝나는 경우가 많음.
3. 다른 의적 원뿔·위치가 약 0.1초 늦게 따라옴(스냅샷 보간).
4. 의적 몸 그림자는 손전등뿐 아니라 모든 빛에서 꺼짐(엔진에 빛별로 끄는 기능이 없음).
5. `L_InteractionTest`는 예전처럼 어두움(맵 밝기는 저택 레벨만).
6. 다음 판에서 캐릭터·퍽을 다시 골라야 함. 창고 문 위 안내가 "갇힌 의적이 없습니다"로 보일 수 있음(구출은 됨).
7. 떨어진 보물 줍기는 사람 2명이 필요해 실서버에서 아직 시험 못 함.
8. 정체 모를 저장 안 된 에셋 1개(위 "현재 상태" 참고).
