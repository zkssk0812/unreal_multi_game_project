# 「털어라! 금고!」 PvP 규칙 v1 (2026-11-06 확정분)

> PvE 협동(최대 3인, 탈출) → **PvP 경쟁**으로 변경. 사용자(김윤기)가 2026-11-06 확정한 규칙을 정리한 문서다.
> - **[미정]** = 아직 정하지 않음. 클라이언트는 임시값을 설정값으로만 두고 임의로 규칙을 만들지 않는다.
> - **[설정]** = `DA_VHGameplayConfig` 등 데이터 에셋 값으로 두어 플레이 테스트 중 바꿀 수 있게 한다.
> - 기존 PvE 규칙 문서: `Docs/Archive_PvE/기획서_초안.md`, `Docs/Archive_PvE/게임_시스템.pdf` (이 문서와 다르면 이 문서가 우선)
> - **2026-11-13부터 게임 규칙은 서버 v3.0 기준**이다. 이 문서는 11-06 결정 기록으로 남기며, 서버 규칙과 다르면 서버가 우선이다(차이는 `Docs/작업보고_2026-11-13.md`).

## 1. 콘셉트
- 도둑(플레이어) 3명이 로봇 경비원(NPC, 서버 AI)이 지키는 저택에서 **서로 경쟁**한다.
- **탈출구 없음.**

## 2. 승리 조건
- 제한시간 **8분** [설정] 종료 시 **반납 금액이 가장 많은 사람이 승리**.
- 끝날 때 **들고만 있던 아이템은 점수가 아니다** (반납한 금액만 점수).
- 동점 처리 **[미정]**

## 3. 능력치
| 항목 | 값 | 비고 |
|---|---|---|
| HP | 100 [설정] | 자연 회복 없음 |
| SP | 100 [설정] | 자연 회복. 0이 되면 최대치까지 회복될 때까지 특수 동작 불가(= 기존 탈진) |
| SP 소비 특수 동작 | 달리기, 구르기 | |
| 공격 | SP 사용 안 함 | |

## 4. 사망·리스폰
| 구분 | 들고 있던 환금 아이템 | 무기 | 반납 금액 | 리스폰 대기 |
|---|---|---|---|---|
| 다른 플레이어에게 사망(PvP) | 그 자리에 떨어짐(다른 사람이 주울 수 있음) | 소멸(삼단봉 제외) | **10%** 소멸 [설정] | **5초** [설정] |
| 경비원(NPC)에게 사망 | 소멸 | 소멸(삼단봉 제외) | **40%** 소멸 [설정] | **10초** [설정] |

- **보물은 예외**: 누구에게 죽든 사라지지 않고 그 자리에 떨어진다.
- 리스폰: **처음 시작 위치**, HP·SP 최대, 상태이상 삭제, 스킬 쿨타임 초기화, 삼단봉 보유, **5초 무적** [설정].
- 리스폰 무적 중 공격하면 무적이 풀리는지 **[미정]**

## 5. 금고
- 게임 시작 시 **1개만** 생성(기존 금고 후보 위치 중).
- 열면 **보물 1개** 등장. 열었을 때 **전체 공지**.
- **보물이 반납되면** 새 금고 1개 생성(직전 위치 제외).
- 진행도는 금고에 남아 다른 사람이 이어서 열 수 있다.
- 동시에 두 명이 열 수 없다.
- 금고 여는 시간 **[미정]** → 임시값 **60초** [설정]

## 6. 반납지점
- **2곳** [설정, 1곳도 가능].
- **60초마다** 다른 곳으로 이동 [설정].
- 나머지는 기존 규칙과 같다(방 바닥 1m 정사각형, 조명과 관계없이 보임, 짧게 누르기로 들고 있는 환금 아이템 전부 반납, 50초에 빨간색 경고 등).

## 7. 운반
- **무게 제한 없음.**
- **인벤토리 없음** (가진 아이템 목록은 데이터로만 관리).
- 잡동사니(낮은 가치 환금 아이템)가 어디서 얼마나 나오는지 **[미정]**

## 8. 삭제되는 기존 규칙
- 무게
- 숨는 곳
- 인벤토리(1~8번 선택)
- 소리로 경비원 유인 (**소리 자체는 유지**)
- 탈출구
- 창고 감금·구출 (죽으면 리스폰하므로)

## 9. 무기
- 최대 **2개**, **마우스 휠**로 교체, **꾹 누르면 공격**, 버릴 수 없음.
- 새 무기를 얻으면 들고 있던 무기와 교체.
- 탄약 아이템 없음(다 쓰면 소멸).
- 무기 2칸에 삼단봉이 포함되는지 **[미정]**

| 무기 | 사용 횟수 | 대미지 | 연사 | 비고 |
|---|---|---|---|---|
| 삼단봉 | 영구 | 10 | DPS 30 | 사망해도 유지 |
| 테이저건 | 1회 | 1 | — | 맞으면 2초 경직 |
| 권총 | 12회 | 10 | 초당 4발 | |
| 화염방사기 | 90회 | 2 | 초당 30발 | |
| 도검 | 영구 | 25 | DPS 50 | |

## 10. 상자·필드 아이템
- 상자: 공격으로 부수면 **확률적으로 무기 드롭** [설정: 확률표].
- 필드 아이템(획득 즉시 사용): 회복약 **소 10 / 중 30 / 대 50**.

## 11. 스킬 (1개 선택, 전부 쿨타임 30초 [설정])
| 스킬 | 효과 |
|---|---|
| 사제 테이저건 | 적중 시 2초 경직. 발동 직후 쿨타임 |
| 끈끈이 투척 | 발동 1초 뒤, 이동 반대 방향 1m 뒤에 반경 3m 함정 10초. 위에 있는 모든 플레이어(설치자 포함)·경비원 이동속도 50% 감소 |
| 카멜레온 은신 | 20초간 다른 플레이어·경비원에게 안 보임. 다시 누르면 해제. 이동속도 80% 감소, 특수 동작 불가, 공격하거나 공격받으면 해제, 상호작용 가능. 쿨타임은 해제 시점부터 |

## 12. 퍽 (3개 선택)
| 퍽 | 효과 |
|---|---|
| 방탄조끼 | 리스폰 전까지 1회용 보호막 HP 20 |
| 기사회생 | 리스폰 전까지 1번 HP 1로 생존 |
| 유용한 도구 | 작업 속도 10% 증가 |
| 운동화 | 달리기 속도 20% 증가 |
| 보물탐색 | 누군가 보물을 획득하면 미니맵에 방향 표시 |
| 로봇탐지 | 미니맵에 경비원 위치 표시 |
| 생체감지 | 미니맵에 다른 플레이어 위치 표시(은신 중인 사람도 미니맵에만 표시) |

## 13. 경비원 (서버 AI, 클라이언트는 표시만)
- 로봇. 플레이어 속도의 **70%**로 탐색.
- 발견 시 추격·**기관총 사격**: 대미지 10, 초당 10발, 타겟 중심 60도 부채꼴 랜덤 난사.
- 회전이 매우 느림.
- **HP 200**. 0이 되면 **5초 자가 수리**(무적·정지) 후 HP 200 회복.
- 타게팅: 먼저 발견한 사람 → 시야에 둘이면 가까운 사람 → 타겟이 아닌 사람에게 맞으면 그 사람으로 변경.

## 14. HUD
| 위치 | 내용 |
|---|---|
| 좌상단 | 미니맵(반납지점과 남은 시간 표시) |
| 우상단 | 남은 시간, 내 반납 금액, 그 아래 다른 플레이어 반납 금액과 순위 |
| 우측 | 현재 들고 있는 환금 아이템 가치 |
| 좌하단 | 닉네임, 캐릭터 이미지, HP(빨강, 보호막은 HP 바 위에 겹쳐 표시), SP(파랑), SP 아래 스킬 아이콘·쿨타임, 무기1·무기2와 남은 사용 횟수 |
| 캐릭터 머리 위 | 닉네임 |
| 추가 | 알림 영역(보물 획득·처치), 사망·리스폰 카운트다운, 금고 진행 막대 |

## 15. [미정] 항목 모음 (임의로 정하지 않음)
| 항목 | 클라이언트 처리 |
|---|---|
| 금고 여는 시간 | 임시 60초, 설정값 |
| 잡동사니 출처·양 | 구현 보류 (지금은 보물만 환금 아이템) |
| 무기 2칸에 삼단봉 포함 여부 | 다른 무기가 생기는 3단계 전에 결정 필요 |
| 리스폰 무적 중 공격 시 무적 해제 여부 | 2단계 구현 전에 결정 필요 |
| 동점 처리 | 결과창 순위 표시 전에 결정 필요 |
| 손전등·어두운 배경 유지 여부 | 관련 코드는 건드리지 않음 |

## 16. 진행 단계
1. 규칙 정리 + 코드 분석 + 계획 (이 문서)
2. 1차 목표: HP·삼단봉, PvP 공격·처치, 사망 패널티·드롭, 리스폰·무적, 금고 1개, 반납지점 2곳, 8분 승리·결과창 순위, 삭제 항목 정리, HUD 기본. Mock(로컬 판정)으로 시험
3. 2차 목표: 나머지 무기, 상자, 회복약, 스킬 3종, 퍽 7종, 미니맵
