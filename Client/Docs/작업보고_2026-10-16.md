## 3. 에디터 크래시 기록 (해결됨)
- 증상: 로그인 화면으로 넘어간 다음 프레임에 `EXCEPTION_ACCESS_VIOLATION`(CoreUObject/SlateCore/Slate). Slate.txt상 Prepass(위젯 크기 계산) 중.
- 원인: 엔진의 `UEditableTextBox::SetWidgetStyle`이 내부 복사본이 아니라 **넘겨받은 인자(InStyle)의 주소**를 Slate에 넘김(EditableTextBox.cpp 397행). 공통 스타일 코드(`UVHUIStyle::ApplyTextBox`)가 지역 변수를 넘겨서, 함수가 끝난 뒤 Slate가 사라진 메모리의 글꼴 정보를 읽었다. 이름 입력칸이 처음 나오는 화면이 로그인이라 거기서 터졌다.
- 수정: 설정 직후 `Box->SetWidgetStyle(Box->GetWidgetStyle())`로 위젯 내부 복사본 주소를 다시 넘김. 수정 후 로그인·로비·대기실 반복 테스트에서 크래시 없음.
- 크래시 시점의 미커밋 작업: 로그인 화면 C++과 WBP_Login(저장은 됨), 이후 화면 C++ 4개. 모두 이후 커밋에 포함됨. 에셋 손실 없음.

## 4. 남은 문제
- 엔진 PDB(디버그 심볼)가 설치돼 있지 않아 크래시 호출 스택에 함수 이름이 안 나온다. 필요하면 에픽게임즈 런처 → 라이브러리 → 엔진 버전 옆 ▼ → 옵션 → "디버깅용 에디터 심볼"을 설치(용량 큼).
- 화면 문구를 `FText::FromString`으로 만들어서 다국어 번역 대상이 아니다(한국어 전용이면 문제 없음).
- `InputMode:UIOnly - Attempting to focus Non-Focusable widget` 오류 로그가 화면마다 1줄 나온다. 동작에는 영향 없음(화면 루트 위젯이 포커스 불가). 추후 루트를 포커스 가능하게 바꾸면 사라진다.
- 엔진 메뉴로 빈 레벨을 만드는 MCP 도구가 없어서 L_MainMenu는 사용자가 직접 만들었다(파일 → 새 레벨 → 빈 레벨).
- 방 목록은 첫 페이지(최대 20개)만 받는다. 방이 20개를 넘으면 페이지 넘김 UI가 필요하다.

## 8. 발표 대비 메모
- **사용자 결정 요구사항**: 이름은 영문 2~12자(서버는 한글 허용이지만 클라이언트에서 제한), 비밀번호 없음, 방 비밀번호 없음, 프로그램 종료는 메인화면에서만, 게임 시작 버튼 없이 전원 준비 시 자동 시작, 승패는 개인별(탈출 = 승리), 준비 조건은 캐릭터 + 퍽 3개 전부.
- **TCP 스트림 재조립**: TCP는 편지 묶음이 아니라 "물 흐르듯 이어진 바이트"라서 한 번에 받은 데이터에 패킷 반쪽이나 여러 개가 섞일 수 있다. 받은 바이트를 버퍼에 쌓고, 맨 앞 2바이트(size)만큼 모이면 패킷 하나를 꺼낸다. Mock 서버가 일부러 1~97바이트씩 잘라 보내도 정상 동작하는 것으로 검증했다.
- **고정 크기 구조체 + memcpy**: 서버와 같은 `protocol.h`(#pragma pack(1))를 그대로 써서 구조체를 바이트로 복사한다. 그래서 파일을 고치지 않고 네임스페이스로 감싸 쓴다.
- **단계별 패킷 제한**: 서버는 지금 단계(로그인 전/로비/방/게임)에서 허용되지 않은 패킷이 오면 연결을 끊는다. 클라이언트도 같은 표를 갖고 단계를 추적해 보내기 전에 막는다. Mock 서버도 같은 규칙으로 끊어서 실수를 바로 찾을 수 있다.
- **Mock 서버로 서버 없이 개발한 이유**: 서버가 아직 PING만 처리해서, 서버를 기다리면 클라이언트 작업이 멈춘다. 같은 프로토콜 바이트를 주고받는 가짜 서버를 프로그램 안에 넣어 UI 흐름 전체를 먼저 완성했다. 실제 서버가 준비되면 설정 하나(`bUseMockServer`)만 바꾸면 된다(전송 계층 교체 구조).
- **하트비트**: 2초마다 PING, 서버는 10초 동안 소식이 없으면 끊는다. PONG으로 왕복 시간(RTT)과 서버 시각 차이를 잰다.
- **방 안 요청에 개별 응답이 없음**: 캐릭터 선택 등은 성공하면 방 전원에게 최신 방 상태(SC_ROOM_STATE)가 오고, 실패하면 나에게만 오류가 온다. 그래서 UI는 내가 누른 것을 기억하지 않고 항상 최신 방 상태로 다시 그린다(여러 사람이 동시에 바꿔도 화면이 서버와 어긋나지 않는다).
- **C++ 로직 + 블루프린트 배치**: 화면 동작은 C++, 위젯 배치는 WBP(BindWidget 이름으로 연결), 색·글꼴은 데이터 에셋 한곳 → 디자인이 정해지면 코드 없이 교체 가능.
- **크래시 디버깅 사례**: 엔진 함수가 인자의 주소를 저장하는 것을 소스에서 찾아 원인을 확정했다(지역 변수 수명 문제, 3장 참고).
