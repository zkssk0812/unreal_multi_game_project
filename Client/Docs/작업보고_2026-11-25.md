- 정호님 답변: ① 상호작용 중이면 서버는 새 상호작용(문 포함)을 InvalidState 로 거절하고 작업을 이어 간다 → 작업 중 F = 작업 취소는 그대로, InvalidState 가 오면 안내가 이상하지 않은지만 확인. ② 서버 문간 점유 = above_door 사각형을 사방 40cm 넓힌 범위에 몸 중심 → 클라 "문간에 서 있어서 닫을 수 없습니다" 범위를 똑같이. 다른 봇이 문간에 있을 때 TargetBusy 안내 확인.
- 확인: 경계 안·밖 몇 cm 에서 클라 안내와 서버 판정이 같은지 로그로. 작업보고 짧게, 커밋 → push. 규칙 같음(서버 코드 수정 금지 등).

- 처음 `vh.WorkBox` 는 F 를 바로 눌러 포커스가 안 잡혀 작업이 시작되지 않았다 → 0.25초 뒤 누르게 고침.
- 빌드 성공(에디터 닫고), 한 판·프레임은 다시 재지 않았다(바뀐 곳이 문 닫기 판정·안내 문구뿐).
