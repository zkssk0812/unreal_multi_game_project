- 기본 색 흰 본체 + 검은 테두리 2px, 지름 60px, 굵기 4px, 사거리 밖 = 빨강(투명도 0.9). 화염 부채꼴은 서버 반각 15°를 화면에서 1.6배로 넓혀 그림(가늘면 안 보여서).
- 근접·테이저·화염의 사거리 판정 여유 40cm(서버 몸 반지름, 상대 몸 끝까지 닿음). 투척은 여유 없음.
- 히트 마커는 플레이어·경비원만(상자는 `bHitMarkerOnBoxes` 로 켤 수 있음). 쓰러뜨림 = 플레이어(서버 SC_DOWNED). 경비원은 쓰러지지 않아 쓰러뜨림 표시 없음.
- 반동 세기(px): 맨손 6·삼단봉 7·도검 8·빔 소드 9·권총 9·화염 3·레일건 26·테이저건 13·수류탄 10·지뢰 8·사제 테이저 12.

## 발표 대비 메모
- **왜 바꿨나**: 운영체제 십자 커서는 1px 선이라 밝은 바닥·폭발 위에서 사라진다. 게임은 마우스 = 조준이라 커서가 안 보이면 못 싸운다 → "가시성"이 1순위(사용자 기준: 48px·3px·어두운 테두리).
- **어두운 테두리 원리**: 같은 선을 검은색으로 조금 두껍게 먼저 그리고, 밝은 선을 그 위에 그린다 → 밝은 바닥에선 검은 테두리가, 어두운 바닥에선 흰 본체가 보인다(자막 글자 테두리와 같은 원리).
- **해상도**: 숫자는 1080p 기준 px 이고 언리얼 UI 배율(화면 짧은 변 기준)로 그려서 720p·1440p 에서도 화면 대비 같은 크기.
- **히트 마커는 서버 판정만**: 클라가 "맞았겠지" 하고 띄우면 서버와 다를 수 있다(닫힌 문·은신 등). 서버가 SC_DAMAGE/SC_DOWNED 를 보낼 때만 띄운다 — 시험에서도 닫힌 문에 막힌 총알엔 X 가 안 떴다.
- **커서 숨김**: 언리얼 플레이어 컨트롤러 커서를 None 으로 바꿔 운영체제 커서를 숨기고, 메뉴 레벨은 다른 컨트롤러라 자동으로 평범한 화살표. 일시정지 중엔 컨트롤러 틱이 멈춰서 엔진 코어 티커로 매 프레임 확인한다.
- **연속 프레임 촬영**: 게임 안 화면 저장은 한 장마다 0.3초씩 멈춰 애니메이션이 망가진다 → 로그에 "발사" 줄이 찍히는 순간 바깥(PowerShell)에서 화면을 초당 30장 넘게 찍었다.
