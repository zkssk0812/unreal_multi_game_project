## 발표 대비 메모
- **손 소켓 + 두 뼈 IK**: 무기를 손 뼈에 붙인 "소켓"에 달고, 코드가 어깨와 팔꿈치 각도를 계산(두 뼈 IK)해 손을 원하는 자리로 보낸다. 그래서 걷기·뛰기 애니메이션 위에서도 무기가 손에서 떨어지지 않고, 위에서 보면 팔이 조준 방향을 가리킨다.
- **애니메이션 파일 없이 동작 만들기**: 키 프레임(시간·손 위치·무기 각도·허리 회전)을 데이터 에셋에 적고, 그 사이를 부드럽게 이어 뼈를 돌린다. 팀 캐릭터 애니메이션이 오면 같은 칸에 몽타주만 넣으면 바뀐다.
- **서버 이벤트로 재생**: 공격 판정은 서버가 한다. 클라는 서버가 보낸 "공격했다(SC_FIRE)"를 받고 쏜 사람의 동작을 재생하므로, 내 화면과 다른 사람 화면이 같고 서버 연사 속도와 어긋나지 않는다. 동작 길이는 서버 공격 간격보다 짧게 자동 조절한다.
- **테스트를 위한 명령**: 서버 없이도 `vh.WeaponAnim 2 0.14`처럼 동작의 특정 순간에 멈춰 찍을 수 있어, 10종을 같은 조건에서 비교했다.

# ④ 무기 사용 이펙트 (2026-11-17 오후~) — 진행 기록

## 사용자 결정 (2026-11-17)
- 이펙트 표(`Docs/Design/무기_이펙트_표_2026-11-17.md`) 그대로 진행. 근접 판정 부채꼴은 아주 옅게, 연막은 회색.
- 폭발·연막·화염방사기 불꽃·피격 불꽃 4가지는 **엔진 기본 나이아가라 템플릿**으로(유료·외부 에셋 없이). 어렵거나 에디터 + 봇 1명 95fps 아래면 도형 방식.
- 레일건 반동·버팀에서 총이 머리 위를 지나는 것처럼 보이는 문제 확인.

- 묶음마다 커밋·push, 여기에 어디까지 했는지 적기.

## 구조
- 새 월드 서브시스템 `UVHWeaponFxSubsystem`(`Gameplay/VHWeaponFx.*`): 무기 동작의 연출 순간(`OnAnyActionEffect`)과 서버 이벤트(`OnFire`·`OnDamage`·`OnProjectile`·`OnExplosion`·지뢰·연막 엔티티)를 받아 그린다. 화염 줄기·레일건 충전·감전·불붙음·날 잔상은 매 프레임.
- 판정 범위 도형: 재질 하나 `/Game/VaultHeist/FX/M_VHFxShape`(부채꼴·링·섬광·별을 파라미터로, `Tools/WeaponBuild/setup_fx.py shape`). 연출 액터 `AVHFxActor`에 평면 도형·3D 모델·쓸기(궤적이 팔을 따라 그려짐)·돌기 추가.
- 나이아가라: `Tools/WeaponBuild/setup_niagara.py`가 MCP로 엔진 템플릿에서 시스템을 만들고 `User.Color`·`User.Radius`(판정 반지름) 변수를 모듈 입력에 연결. `DA_VHWeaponCatalog`의 `bUseNiagara`를 끄면 전부 도형 방식.
- 개발 명령: `vh.Fx N`(1~10 무기 동작+이펙트), `vh.Fx hit N`(피격), `vh.Fx smoke`, `vh.FxPlane`(평면 방향 보정). 촬영은 `slomo 0.02~0.05`로 느리게.
- 레일건·화염방사기 든 자세를 앞·아래로(레일건 X 28→46, Z 114→100), 레일건 반동은 뒤로 미는 쪽(−22cm·22° → −14cm·5°, 허리 젖힘 −12° → −6°).

## 묶음 1: 근접 — 완료 (커밋 아래)
- 궤적: 판정 부채꼴(반지름 200/300/400cm, 반각 60°)을 아주 옅게 + 바깥 호. 삼단봉은 가운데→양옆, 도검·빔 소드는 오른쪽→왼쪽으로 0.06~0.09초에 그려지고 0.32초에 사라짐. 빔 소드 날 잔상(0.025초마다 날 모양, 0.12초).
- 피격: 도형 별 섬광(0.22초) + 나이아가라 불꽃 `NS_VH_HitSpark`(RadialBurst 템플릿, 리본 2개 제거, 0.15~0.35초). 감전(테이저·감전 지뢰) 2초 전기 줄기, 불붙음(화염) 마지막 피격 뒤 0.5초.
- 확인: `vh.Aim -90` + `slomo` + `vh.Fx 1~3`, `vh.Fx hit 2/7/5` → `Saved/WeaponBuild/Anim/fx1_melee.png`.
- 고친 것: 나이아가라 알갱이가 3~8cm라 탑뷰에서 안 보임 → 12~22cm, 색 밝기 6배는 밝은 바닥에서 하얗게 떠서 2.5배. 전기 줄기·탄 궤적은 연출 기본 재질(M_VHFx)이 회색으로 흐려 도형 재질로 바꿈.
- 코드에는 원거리·투척·설치도 들어 있다(아직 화면 확인 전 → 묶음 2·3).

## 묶음 2: 원거리 — 완료 (커밋 아래)

- 테이저: 지그재그 전기 줄기 2가닥(사거리 300cm 또는 맞은 대상), 0.3초 동안 0.06초마다 모양이 바뀜.

## 남은 문제
- 탑뷰라 앞구르기의 "위아래 회전"은 웅크린 모양 변화로만 읽힌다. 다리가 거꾸로 돌 때(60%) 발이 조금 벌어져 보인다 → 필요하면 `Knee Bend`·`Hip Flex`를 키우거나 팀 몽타주로.

## 발표 대비 메모 (⑤⑥)
- **줍기가 안 되는 것처럼 보인 이유**: 서버는 소비 아이템을 한 개만 들게 하고, 주우면 들고 있던 것을 그 자리에 내려놓는다. 같은 종류를 주우면 "바꿨는데 결과가 같아서" 화면에 아무 변화가 없었다. 로그로 서버가 정상 응답(SC_PICKUP)한 것을 확인하고, 클라에서 같은 종류는 미리 막고 알려 주게 했다 → 서버 코드를 고치지 않고 해결.
- **구르기 = 뼈 몇 개 + 루트 한 바퀴**: 허리·다리·팔 뼈를 굽혀 공 모양을 만들고, 루트 뼈 하나를 몸 가운데 축으로 360° 돌리면 온몸이 따라 돈다. 키 시간을 비율로 둬서 서버 무적 시간(0.5초)과 언제나 같은 길이.
- **다른 플레이어도 같은 동작**: 서버가 보내는 상태 비트(ES_DODGING)가 켜지는 순간에 같은 코드로 재생하고, 방향은 그 사람이 실제로 움직인 쪽으로 정한다.

- **팔 IK·손가락 쥐기**: 무기 손잡이가 놓일 자리로 손을 보내는 두 뼈 IK + 손가락 뼈를 자기 축으로 말기. 축은 기준 자세(손바닥 방향)에서 계산해 모델이 바뀌어도 데이터만 다시 만든다.
- **같은 사람 = 같은 색**: 모든 클라가 서버에서 같은 엔티티 목록을 받으므로 엔티티 번호 순서로 색을 정하면 따로 통신 없이 화면마다 같은 색이 된다.
