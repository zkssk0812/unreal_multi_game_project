# 「털어라! 금고!」 무기 3D 모델 제작 규격 (2026-11-20)

모델러분께: 이 규격대로 만들어 주시면 게임에 바로 끼울 수 있습니다.
모양·색은 팀 확정 구상안 **v2.2** (`Docs/Design/Weapons_v2.2/` 카드 10장)를 따라 주세요.
게임은 위에서 내려다보는 **탑뷰**라서, 무기는 대부분 **위에서 본 실루엣**으로 구분됩니다.

---

## 1. 파일
| 항목 | 규격 |
|---|---|
| 형식 | **FBX** (바이너리, FBX 2018 이상이면 됨). 무기 하나당 파일 하나 |
| 종류 | 움직이지 않는 모델(스태틱 메시). 뼈대·애니메이션 없음 |
| 여러 조각 | 괜찮습니다(게임에서 하나로 합칩니다). 단, 조각마다 원점이 같아야 합니다 |
| 텍스처 | PNG, FBX 와 같은 폴더에 |

## 2. 크기와 방향 (가장 중요)
- **단위: 1 = 1cm, 실제 크기로.** (게임에서 탑뷰용으로 2배쯤 키워 보여 주는 건 저희가 합니다)
- **앞(총구·칼끝) = +X, 위 = +Z** (언리얼 엔진 기준 축).
- **기준점(원점) = 오른손이 쥐는 손잡이 가운데.** 지뢰 2종만 **바닥 가운데**.

```
   옆에서 본 모습 (+Z 위, +X 앞)

        +Z
         ↑
         |      ┌──────────────┐
         |  ┌───┤ 몸통          ├══ ● Muzzle(총구)
         |  │   └──────────────┘
         ●──┘ ← 원점 = 손잡이 가운데 (Grip)
         └──────────────────────→ +X (앞)
```

| 번호 | 무기 | 실제 크기 기준 (앞뒤 길이) | 원점 |
|---|---|---|---|
| VH-01 | 삼단봉 (펼친 상태) | 약 65cm | 손잡이 가운데 |
| VH-02 | 도검 | 약 90cm | 손잡이 가운데 |
| VH-03 | 빔 소드 (날 켠 상태) | 약 100cm | 손잡이 가운데 |
| VH-04 | 권총 | 약 22cm (높이 13cm) | 손잡이 가운데 |
| VH-05 | 화염방사기 | 약 95cm | 뒤쪽 손잡이(방아쇠) 가운데 |
| VH-06 | 레일건 | 약 120cm | 뒤쪽 손잡이(방아쇠) 가운데 |
| VH-07 | 테이저건 | 약 24cm | 손잡이 가운데 |
| VH-08 | 수류탄 | 약 9cm × 13cm(높이) | 몸통 가운데 |

- 크기가 조금 달라도 괜찮습니다(게임에서 무기별로 배율을 고칠 수 있음). **단위(cm)와 방향만** 꼭 맞춰 주세요.
- 프로그램마다 내보내기 축 설정이 달라서, **첫 무기 하나를 먼저 보내 주시면** 방향이 맞는지 확인해 드리겠습니다.

## 3. 소켓 (이펙트·손 위치를 붙이는 점)
빈 물체(블렌더 Empty, 맥스 Dummy/Point, 마야 Locator)를 만들고 이름을 **`SOCKET_` + 아래 이름**으로 지어 모델에 붙여(자식으로) 주세요.
예: `SOCKET_Muzzle`. 대소문자까지 정확히. 언리얼이 FBX 를 가져올 때 자동으로 소켓이 됩니다.

| 소켓 이름 | 놓는 곳 |
|---|---|
| `SOCKET_Grip` | 오른손이 쥐는 손잡이 가운데 (= 원점. 원점과 같으면 넣어도 되고 안 넣어도 됨) |
| `SOCKET_Muzzle` | 총구 끝 가운데 (불꽃·총알·빔이 나가는 곳) |
| `SOCKET_BladeBase` | 칼날(봉)이 시작하는 곳 — 손잡이 가드 바로 앞, 날 가운데 |
| `SOCKET_BladeTip` | 칼끝(봉 끝) 가운데 |
| `SOCKET_SupportHand` | 왼손이 받치는 곳 (총열 아래 손잡이 / 지뢰 왼쪽 가장자리) |

### 무기별로 필요한 소켓
| 번호 | 무기 | Grip | Muzzle | BladeBase | BladeTip | SupportHand |
|---|---|:-:|:-:|:-:|:-:|:-:|
| VH-01 | 삼단봉 | ● | | ● | ● | |
| VH-02 | 도검 | ● | | ● | ● | |
| VH-03 | 빔 소드 | ● | | ● (빛나는 날 시작) | ● | |
| VH-04 | 권총 | ● | ● | | | |
| VH-05 | 화염방사기 | ● | ● (노즐 끝) | | | ● (앞쪽 손잡이) |
| VH-06 | 레일건 | ● | ● (레일 사이 끝) | | | ● (앞쪽 손잡이) |
| VH-07 | 테이저건 | ● | ● (전극 끝 가운데) | | | |
| VH-08 | 수류탄 | ● | | | | |
| VH-09 | 폭발 지뢰 | | | | | ● (왼쪽 가장자리) |
| VH-10 | 감전 지뢰 | | | | | ● (왼쪽 가장자리) |

```
근접 (옆모습)                          긴 총 (옆모습)
 ●Grip  ●BladeBase          ●BladeTip      ●SupportHand        ●Muzzle
 ║▐█▌══════════════════════════▶        ┌──┴────────────────────┐
 손잡이   가드  날                    ●Grip┘ 방아쇠             총구

지뢰 (위에서)
      ┌─────────┐
 ●────┤  ( ◎ )  │  ← 원점 = 바닥 가운데, ● = SupportHand(왼쪽 가장자리)
      └─────────┘    오른손은 오른쪽 가장자리를 쥡니다
```
- 소켓이 빠져도 게임은 돌아갑니다(모델 크기로 자리를 계산). 다만 정확한 자리는 소켓이 있어야 합니다.
- 지금 게임에 들어 있는 임시 모델 기준 예시 값(cm, 원점 기준 앞 X·위 Z): 권총 Muzzle (18.6, 1.2), 도검 BladeTip (69.7, 0.8), 화염방사기 SupportHand (28.3, −1.7).

## 4. 폴리곤·텍스처 권장
탑뷰 1080p 화면에서 무기는 가로 20~70 픽셀 정도로 보입니다. 세밀한 디테일보다 **실루엣과 발광 띠**가 중요합니다.

| 무기 | 삼각형 수 권장 | 텍스처 |
|---|---|---|
| 권총·테이저건·수류탄 | 1,000 ~ 2,500 | 512 × 512 |
| 삼단봉·도검·빔 소드 | 1,500 ~ 3,000 | 1024 × 1024 |
| 화염방사기·레일건 | 3,000 ~ 5,000 | 1024 × 1024 |
| 지뢰 2종 | 1,000 ~ 2,500 | 512 × 512 |

- 텍스처: Base Color, Normal, ORM(빨강 = AO, 초록 = 거칠기, 파랑 = 금속) — 없으면 Base Color 만이라도 괜찮습니다.
- 재질: 구상안 공통 재질(무광 블랙·브러시드 스틸·카본·짙은 가죽·황동 포인트).
- **발광 띠는 따로 재질 칸으로, 재질 이름에 `Glow` 를 넣어 주세요** (예: `M_Glow`). 게임이 분류 색(근접 빨강·원거리 시안·투척 주황·설치 라임)으로 자동으로 바꿔 칠합니다. 띠의 색은 아무 색이어도 됩니다.
- 재질 칸은 무기당 5개 이하 권장.

## 6. 게임에서 이렇게 쓰입니다 (참고)
- **손에 든 모습**: 원점(손잡이)이 캐릭터 오른손에 붙고, 앞(+X)이 마우스 커서 방향을 봅니다. 근접 무기는 날을 옆으로 눕혀 들어 탑뷰에서 날 옆면이 보입니다.
- **바닥에 떨어진 모습**: 같은 모델을 눕혀서 돌립니다 → 위에서 봐도 무엇인지 알 수 있는 실루엣이면 좋습니다.
- **수류탄**: 손에서 떠나 돌면서 날아갑니다. **지뢰**: 바닥에 놓입니다(밑면 평평하게).
- 이펙트는 게임이 그립니다(총구 불꽃·칼 궤적·빔 등). 모델에 불꽃 같은 것은 넣지 않아도 됩니다.
