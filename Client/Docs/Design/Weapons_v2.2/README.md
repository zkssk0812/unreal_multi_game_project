# 무기 구상안 v2.2 (팀 확정본, 2026-11-16 승인)

게임 안 무기 10종의 모양·색 기준 자료다. 3D 모델·아이콘·연출 색은 이 자료를 따른다.

## 파일
- `01_baton_v2.2.png` ~ `10_shock_mine_v2.2.png`: 무기별 카드(옆모습, 탑뷰 실루엣, 디자인 의도). 원본 3200px를 가로 1600px로 줄였다.
- `weapon_concepts_v22.html`: 그림 원본(코드로 그린 SVG). 브라우저로 열면 전체 시트, 주소 끝에 `?w=04`처럼 붙이면 그 무기 카드만 나온다. 큰 그림이 필요하면 이 파일에서 다시 뽑는다.

## 디자인 규칙
- **발광 색 = 분류**: 근접 `#FF2D55`(루비 레드) · 원거리 `#35D6FF`(아이스 시안) · 투척 `#FF9A1F`(앰버 오렌지) · 설치 `#B6FF3A`(라임)
- **실루엣 = 무기**: 같은 분류는 색이 같으므로 모양으로 구분한다.
- **공통 재질**: 무광 블랙(숯색) · 브러시드 스틸 · 카본 · 짙은 가죽 · 황동 포인트
- **각인**: 금고 다이얼 로고 + `VH-01` ~ `VH-10`
- **형태**: 매끈한 곡면 + 날카로운 캐릭터 라인
