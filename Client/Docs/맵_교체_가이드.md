|---|---|---|
| 원본 FBX | `Art/Map/Mansion_1F_Blockout.fbx` (Git LFS) | **같은 이름으로 덮어쓰기** |
| 참고 평면도 | `Docs/Mansion_1F_평면도.png` | 새 평면도로 덮어쓰기 |
| 맵 메시 에셋 | `Content/VaultHeist/Maps/Mansion/SM_Mansion_1F` | **리임포트**만 하면 된다 (설정 유지 확인함) |
| 게임 레벨 | `Content/VaultHeist/Maps/Mansion/L_Mansion_1F` | 그대로 |
| 레벨 안 `Map` 폴더 | 맵 메시 액터 `Mansion_1F_Geometry`, 내비 범위 `NavMeshBounds_Mansion` | 그대로 (메시가 바뀌면 자동으로 새 모양) |
| 레벨 안 `Rooms` 폴더 | 방 지역 `Room_01`~`Room_33` (반납지점이 나오는 곳) | **위치·크기만 확인** |
| 레벨 안 `Gameplay` 폴더 | 시작 지점, 금고 후보 10, 탈출구 + 바깥 바닥판, 창고, 숨는 곳 4, 더미 경비원 | **위치만 확인** (끌어서 옮기면 됨) |
| 벽 재질 | `M_VHWallFade` (캐릭터 앞 벽 투명) | 재질 슬롯 이름이 `Walls`이면 자동 유지 |
| 게임이 쓸 레벨 | `Config/DefaultGame.ini` 의 `GameLevel=` | 레벨 이름이 바뀔 때만 수정 |

- 맵 메시와 게임 오브젝트가 **서로 다른 액터**라서, 메시를 다시 가져와도 레벨에 놓은 오브젝트는 사라지거나 움직이지 않는다.
- 단, 모델러가 **원점·단위·방향**을 바꾸면 오브젝트와 맵이 어긋난다 → 5장.

### 좌표 관계 (평면도 ↔ 언리얼) — 2026-10-27 변경: 서버와 같은 좌표
서버 팀원과 결정: **맵 액터는 원점에 회전 없이(0,0,0 / 회전 0) 둔다** = 서버 맵 파일(`mansion_1f_server.json`)과 같은 좌표.
대신 **탑뷰 카메라를 90° 돌려서**(`Map / LevelViewSettings` 액터의 `TopViewYaw = 90`) 화면은 예전처럼 평면도 위쪽 = 화면 위쪽이다.
- **언리얼 X = −평면도 X × 100**, **언리얼 Y = 평면도 Y × 100** (cm)
- 예: 평면도 (X -49m, Y -29.5m) → 언리얼 (X 4900, Y -2950)
- 화면 위 = +Y, 화면 오른쪽 = −X, 화면 왼쪽(서쪽) = +X.
- 게임 HUD의 `위치: (a, b)` 는 언리얼 X/100, Y/100 = (−평면도 X, 평면도 Y) 이다.
- 서버 맵 파일의 벽 93개와 레벨의 벽을 선 쏘기로 비교해 **0.1cm 안에서 일치**함을 확인했다(작업보고 2026-10-27).
- 이전(10-26~10-27): 맵 액터를 Z -90° 돌려 두었다(언리얼 X = 평면도 Y×100, 언리얼 Y = 평면도 X×100). 그때 놓은 오브젝트는 모두 같은 만큼 돌려 옮겼다.

### 충돌
- **벽·바닥 메시 자체를 충돌로 사용**(콜리전 복잡도 = "복합 콜리전을 단순으로 사용", Use Complex Collision As Simple). 사용자 결정 (가).
- FBX 안의 충돌 박스 98개(CollisionBox000~097)는 가져올 때 메시 안의 보이지 않는 충돌 요소로 들어오지만, 위 설정 때문에 **쓰이지 않는다**. 보이는 벽으로 겹쳐 들어오지도 않는다.

## 2. 교체 순서

### 2-1. 파일 덮어쓰기
1. 모델러에게 받은 FBX를 `C:\UnrealProjects\MCPTest\Art\Map\Mansion_1F_Blockout.fbx` 에 **같은 이름으로 덮어쓴다**.
2. 새 평면도가 있으면 `Docs\Mansion_1F_평면도.png` 도 덮어쓴다.

### 2-2. 다시 가져오기 (리임포트)
1. 에디터 아래 **콘텐츠 드로어**(`Ctrl + Space`) → `콘텐츠 → VaultHeist → Maps → Mansion`
2. **SM_Mansion_1F** 더블클릭 → 스태틱 메시 에디터가 열린다.
3. 위쪽 툴바의 **[메시 리임포트]** 클릭. (파일 위치가 바뀌었으면 옆의 **[대화창을 사용하여 메시 리임포트]** 로 새 파일을 고른다)
   - 다른 방법: 콘텐츠 드로어에서 SM_Mansion_1F 우클릭 → **리임포트**
4. 오른쪽 아래 "리임포트 성공" 알림이 뜨면 **저장**(`Ctrl + S`).

### 2-3. 메시 설정 확인 (스태틱 메시 에디터 오른쪽 디테일 패널)
| 확인할 것 | 위치 | 정상 값 |
|---|---|---|
| 충돌 방식 | 콜리전 → **콜리전 복잡도** | 복합 콜리전을 단순 콜리전으로 사용 (Use Complex Collision As Simple) |
| 벽 재질 | 머티리얼 슬롯 `Walls` | `M_VHWallFade` |
| 바닥 재질 | 머티리얼 슬롯 `Floor` | `WorldGridMaterial` (아무거나 가능) |

- 2026-10-26에 실제로 리임포트해서 위 3가지가 **그대로 유지되는 것을 확인**했다.
- 모델러가 재질 이름(슬롯 이름)을 바꿨다면 슬롯이 새로 생기므로 벽 슬롯에 `M_VHWallFade` 를 다시 넣는다. (안 넣으면 캐릭터 앞 벽이 투명해지지 않는다)

### 2-4. 레벨에서 맞는지 확인
1. 콘텐츠 드로어 → `Maps → Mansion → L_Mansion_1F` 더블클릭
2. **위에서 보기**: 뷰포트 왼쪽 위 **원근 → 위쪽**(Top) 으로 바꾸고, 표시 → **조명 끄기(언릿)** 로 보면 벽이 잘 보인다.
3. 아웃라이너의 `Map / Mansion_1F_Geometry` 위치가 **(0,0,0)**, 회전이 **0** 인지 확인(서버 좌표와 같아야 함). `Map / LevelViewSettings` 의 **Top View Yaw = 90** 인지 확인.
4. 아웃라이너 `Rooms` 폴더를 전부 선택하면 방 지역 상자(하늘색 선)가 보인다 → 새 벽과 맞는지 본다.
   - 방이 생기거나 없어졌으면: 기존 `Room_xx` 를 복제(`Ctrl + D`)·이동·크기 조절(스케일)하거나 삭제한다. 디테일 패널의 **Room Name**(방 이름), **Allow Return Point**(반납지점 허용)를 맞춘다.
   - 문이 없는 방(지금 11·13·20번)에 문이 생기면 해당 Room의 **Allow Return Point를 켜고** 이름의 "(문 없음)"을 지운다.
5. `Gameplay` 폴더의 오브젝트가 벽에 박히거나 문을 막지 않는지 확인하고, 문제가 있으면 **끌어서 옮긴다**.
   - 탈출구(`ExitGate`)는 바깥으로 뚫린 곳에 문 앞면이 안쪽을 보게 두고, 문 뒤 바깥에 `Floor_Exit`(바닥판)이 있어야 한다.
   - 탈출구가 아닌데 바깥으로 뚫린 곳(지금은 현관 정문)은 `InvisibleWall_FrontDoor`(게임 중 안 보이는 벽)로 막아 두었다. 모델러가 바깥 바닥을 넣거나 구멍 위치가 바뀌면 이 벽을 옮기거나 지운다.
   - 금고는 후보가 10개 이상이면 된다(매 판 5개 랜덤). 수는 `DA_VHGameplayConfig → Active Safe Count`.
6. **내비게이션(경비원 AI용 길)**: 메뉴 **빌드 → 경로 빌드**. 뷰포트에서 `P` 키를 누르면 초록색 내비 메시가 보인다. 맵 크기가 커졌으면 `Map / NavMeshBounds_Mansion` 상자를 맵보다 크게 늘린다.
7. 레벨 저장(`Ctrl + S`).

### 2-5. 지역·배치 그림 다시 만들기 (선택)
평면도 좌표(m)로 적은 표를 고친 뒤 그림을 다시 만든다. (그림만 만드는 도구이며 레벨을 바꾸지는 않는다. 표는 평면도 좌표라 10-27 좌표 변경과 상관없다)
- 방 지역: `Tools/MapOverlay/rooms.csv` (번호, x1, x2, 위 y, 아래 y, 문 없음 여부, 이름)
- 배치: `Tools/MapOverlay/placements.csv`
- PowerShell에서:
```
& "C:\UnrealProjects\MCPTest\Tools\MapOverlay\draw_overlay.ps1" -Out "C:\UnrealProjects\MCPTest\Docs\Mansion_1F_지역.png"
& "C:\UnrealProjects\MCPTest\Tools\MapOverlay\draw_overlay.ps1" -Placements "C:\UnrealProjects\MCPTest\Tools\MapOverlay\placements.csv" -Out "C:\UnrealProjects\MCPTest\Docs\Mansion_1F_배치안.png"
```
- 평면도 그림의 축 위치(격자 그림의 -100m·0m 눈금 픽셀)가 바뀌면 스크립트 맨 위 `PX`/`PY` 숫자를 고친다.

### 2-6. 플레이 확인 (PIE)
`L_Mansion_1F` 에서 ▶ 플레이 후 콘솔(`~`):
| 확인 | 방법 | 정상 |
|---|---|---|
| 벽 충돌 | 벽으로 걸어가기 | 통과하지 못함 |
| 벽 가림 | 화면 아래쪽 벽에 붙기(`S`) | 벽에 둥근 구멍이 생겨 캐릭터가 보임 |
| 반납지점 | 출력 로그 `[Match] 반납지점 등장: 방 N` | 5곳, 문 없는 방 제외 |
| 금고 | 로그 `[Treasure]` | 5곳 등장, 나머지 "등장하지 않음" |
| 오브젝트 | `VHGoto Safe_03`, `VHGoto Jail`, `VHGoto ExitGate`, `VHGoto HideSpot_1` | 그 앞으로 이동, 손전등(R)으로 비추면 안내 문구 |
| 탈출 | `VHAddValue 10000` → `VHGoto ExitGate` → 문 쪽으로 걷기 | 탈출 → 결과창 |

그다음 메뉴 레벨(`L_MainMenu`)에서 로그인 → 방 → 준비로 들어가 게임 레벨이 저택으로 열리는지 확인한다.

## 3. 레벨 이름이 바뀌거나 층이 늘 때 (예: 2층)
1. `L_Mansion_1F` 를 복제해서 새 레벨을 만들고(조명·후처리·게임 모드가 같이 복사됨) `Map` 폴더의 메시만 새 메시로 바꾼다.
2. 게임이 쓸 레벨을 바꾸려면 `Config/DefaultGame.ini` 의 `[/Script/MCPTest.VHSettings]` 아래 `GameLevel=` 줄을 고치고 에디터를 다시 연다.
3. 기능 테스트 레벨로 돌아가려면 같은 줄을 `/Game/VaultHeist/Maps/L_InteractionTest.L_InteractionTest` 로 바꾼다.

## 4. 모델러가 충돌 박스 이름을 UCX_ 로 바꿔 보내면 (선택지 다)
1. 2장 순서대로 리임포트한다.
2. 스태틱 메시 에디터 → 콜리전 복잡도를 **프로젝트 디폴트**(또는 "단순과 복합")로 바꾸면 UCX_ 박스가 충돌로 쓰인다.
3. 벽 통과·막힘을 PIE로 확인한다. (지금처럼 벽 메시 자체를 충돌로 써도 문제는 없다)

## 5. 원점·단위·방향이 바뀌면
- 모델러가 원점을 맵 가운데로 옮기는 등 **좌표가 바뀌면 모든 오브젝트가 함께 어긋난다.**
- 해결: 아웃라이너에서 `Rooms` 와 `Gameplay` 폴더의 액터를 모두 선택해 **한 번에 같은 거리만큼 이동**한다(맵 메시는 이미 새 위치). 또는 맵 액터 `Mansion_1F_Geometry` 의 위치를 옮겨 예전 자리에 맞춘다(이게 더 쉽다).
- 그래서 모델러에게 **"원점·단위(cm)·축 방향은 앞으로 바꾸지 말아 달라"** 고 요청해 두었다(작업 보고서 "모델러 요청 사항").
