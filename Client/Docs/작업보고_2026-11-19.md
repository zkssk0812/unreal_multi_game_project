## 남은 문제
- **실서버에서 삼단봉 말고 9종은 확인 못 함** (봇이 무기를 못 주움). `vh.WeaponTest N proxy` 로 다른 플레이어 쪽 코드 경로는 확인. 다음엔 봇이 상자 무기를 줍게 하거나 사람이 한 판.
- 열기 일렁임(화염)은 못 만듦: 굴절 재질이 필요해 보류.
- 레일건 "위이잉" 방전음은 높낮이가 내려가지 않음(소리 파일 겹으로만). 화염 반복음(thrusterFire_000 반복)은 이음매가 들릴 수 있음.
- 수류탄 던지기·지뢰 내려놓기 동작은 바꾸지 않음(지금 Mixamo Throw·키 프레임). Lyra `MM_Rifle_GrenadeToss` 곡선은 꺼내 두었음(`lyra_recoil.json` toss).
- 근접 맞은 이펙트·소리는 동작 기준 시간(삼단봉 0.15초 등)만큼 늦게 냄 → 실제 판정 시각과 약간 다를 수 있음(화면 맞춤).
- 섬광 조명 동시 최대 6개 제한. 폭발 섬광이 넓어 화면 전체가 잠깐 주황빛이 됨(0.18초).
- 시험 중 `vh.WeaponTest` 허수아비 이름표(Dummy HP 100)가 가까이 화면에 크게 보임(시험 전용).

## 확인 필요 (가정)
- **Lyra 나이아가라를 가져오지 않음**(의존 206~290MB) → 엔진 나이아가라·도형으로 대신. 괜찮은지.
- 소리 고르기·음량(권총 1.0 기준, 근접 0.6~0.85, 레일건 1.2, 수류탄 1.35, 반복음 0.2~0.5)은 Claude 가 정함.
- 빔 소드 "웅—"은 6m 안에서만 들림, 감전 지뢰 웅웅도 6m.
- 레일건 충전 대신 "쾅 + 방전", 수류탄 튕김 대신 "날아가는 소리" (서버 규칙에 충전·튕김이 없음).
- 화염방사기 맞음 소리 없음(서버 30Hz 맞음).
- 삼단봉 든 자세(앞으로 20°)는 Claude 가 정함(도검·빔 소드는 40° 그대로).

## 발표 대비 메모
- **무기마다 다르게**: 동작(키 프레임 곡선)·소리(여러 파일을 겹쳐 하나의 소리로)·이펙트(리본·도형·나이아가라·조명)를 무기별 표(데이터 에셋) 칸으로 나눠서, 코드는 그대로 두고 표만 바꿔 조정한다.
- **Lyra 를 통째로 안 가져온 이유**: 동작은 손 위치 규칙과 부딪히고 이펙트는 200MB 넘게 딸려 와서, 반동 "곡선 숫자"와 소리 "원본 파일"만 꺼냈다(커맨드렛으로 Lyra 를 열어 스크립트 실행).
- **IK 리타게팅**: 마네킹 뼈대 동작을 우리 의적 뼈대로 옮길 때 팔·다리·척추를 "체인"으로 짝지어 자세를 옮긴다. 손은 그 위에 코드 IK 로 무기 자세에 맞춘다.
- **소리 듣는 위치**: 탑뷰 카메라는 십수 m 위에 있어서 모든 소리가 멀게 들렸다 → 거리 계산은 내 캐릭터에서, 좌우는 카메라에서.
- **서버 규칙에 맞춘 연출**: 레일건은 충전 시간이 없고 수류탄은 튕기지 않는다(서버 판정) → 화면·소리도 그 순간에 맞춘다. 이펙트 크기 = 서버 판정 범위.
