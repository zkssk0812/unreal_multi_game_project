## 남은 문제
- 무기 든 자세(권총·라이플 Idle/Walk/Run)·공격(Shooting·Firing Rifle·근접 베기)·투척은 **바꾸지 않음**: 손 위치·근접 40° 세워 들기·수평 베기를 지키려고 팔은 지금처럼 코드 IK. Mixamo 무기 동작은 경비원에만 씀.
- 받지 않은 동작: 로비·결과(Happy Idle·Victory·Defeated), 은신 이동, 제트팩, 상자 부수기(Searching) → 연결 못 함.
- 몽타주 상체 동작 중 무기는 손을 따라감(마시기·줍기 때 총이 같이 움직임).
- 효과음: 연막·UI 버튼은 칸만 있고 연결 안 함. 소리 크기·감쇠는 귀로 조정 필요.
- 구르기는 Mixamo 2.1초 동작을 0.5초에 넣어 4.2배 빠름.

## 발표 대비 메모
- **블렌드스페이스(시선 기준 이동)**: 몸은 커서를 보고 다리는 이동 방향으로. "이동 방향 − 몸 방향" 각도와 속도 두 값으로 8개 걷기·달리기 동작의 무게를 섞는다. 걸음 속도를 재서 재생 빠르기를 맞춰 발이 덜 미끄러진다.
- **리타게팅을 직접 계산한 이유**: AI 모델 뼈대는 이름만 Mixamo 와 같고 뼈 축이 달라 회전을 그대로 넣으면 몸이 젖혀졌다. FBX 파일 안의 기본 자세(PreRotation)를 읽어 "기본 자세에서 얼마나 돌았나"를 월드 기준으로 옮겼다.
- **몽타주를 그래프 없이**: 다른 플레이어 표시는 애니메이션 블루프린트가 없어 몽타주가 안 됐다 → C++ 에서 몽타주 슬롯을 직접 섞어 내 캐릭터와 똑같이 보이게 했다.
- **화염방사기 버그**: 화면 표시를 "서버가 상태를 알려 줄 때"만 바꿔서 마지막 손 뗌이 반영 안 됐다. 내가 보낸 입력은 보내는 순간 바로 화면에 반영해야 한다.
- **CC0 효과음**: 저작권 표시 없이 쓸 수 있는 소리만, 출처 문서와 License.txt 를 같이 보관.
