## 남은 문제
- 무기가 하나뿐일 때 테이저를 든 채 휠 → 서버가 교체를 `OnlyOneWeapon`으로 거절하고 테이저를 그대로 듦(서버 동작). Q로는 집어넣을 수 있음 → 정호님께 확인 요청.
- 레일건 꾹 누르기: 서버는 잠금이 끝나면 이어서 쏘지만 클라는 클릭 한 번 = 한 발 유지(가정).

## 확인 필요 (가정)
- 쿨타임 중 테이저 Q는 서버에 보내지 않고 알림만 띄움(서버도 Cooldown으로 거절하므로 같은 결과).
- 레일건 충전 중 경직은 취소하지 않음(서버가 쓰러짐만 취소).
- 레일건 연출 시간은 서버 상수(1초·1초)를 클라 코드에 같은 값으로 둠(프로토콜에 없음).

## 발표 대비 메모
- **서버 권위로 옮기기**: 테이저 "들기" 상태를 예전엔 클라만 알아서 다른 사람 화면엔 안 보였다. 서버가 상태 비트(`ES_TASER_READY`)로 알리면서 모든 화면이 같은 상태를 본다 — "보이는 것과 판정이 같은 곳(서버)에서 나온다".
- **레일건 지연 줄이기**: 예전엔 클라가 1초 기다렸다 신호 → 서버 판정까지 왕복이 더해졌다. 이제 누르는 즉시 보내고, 서버가 충전 1초를 세며, 클라는 서버가 보낸 `SC_FIRE` 시각에 맞춰 연출만 한다. 클릭→빔 1.05초.
- **같은 패킷으로 다른 사람 연출**: `SC_FIRE`는 모든 클라가 받으므로, 같은 코드로 내 레일건과 남의 레일건 충전을 똑같이 보여 준다.
- **반납 경고 단순화**: 클라 시계로 따로 계산하던 빨강을 서버 신호 하나로 — 서버 값이 바뀌어도 클라를 고칠 필요가 없다.
