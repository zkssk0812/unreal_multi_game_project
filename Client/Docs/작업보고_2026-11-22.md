## 발표 대비 메모
- **왜 복사 스크립트인가**: 작업 폴더(MCPTest)의 경로·도구·서버 실행 bat이 모두 이 폴더 기준이라 옮기지 않고, 팀 저장소의 `Client/`에 "올릴 파일만" 동기화한다. 팀원 서버 코드(Server/)와 섞이지 않게 `Client/`만 커밋한다.
- **Git LFS**: 언리얼 에셋(.uasset/.umap)·이미지·소리·3D 모델은 큰 바이너리라 Git에는 작은 "포인터"만 두고 실제 내용은 LFS 서버에 둔다. 이번에 일반 Git 3.8 MB + LFS 630 MB.
- **올리기 전 안전장치**: GitHub 한 파일 100MB 한도, LFS 누락, Client/ 밖 변경, 미커밋 변경을 스크립트가 미리 막는다.
- **검증**: 팀 저장소에서 새로 받은 상태로 빌드하고 에디터로 맵을 열어, 의존 에셋이 하나도 빠지지 않았는지 자동 검사했다. 올리기 전 점검에서 Git에 빠져 있던 스켈레톤 에셋(무기 애니메이션이 참조)도 찾아 함께 넣었다.
