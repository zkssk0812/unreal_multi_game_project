# 무기 모델 교체 가이드 (2026-11-20)

모델러분이 보내 주신 무기 FBX 를 게임에 넣는 순서다. 코드는 고치지 않는다.
모델러분께 보낸 제작 규격: `Docs/무기_모델_제작규격.md`

## 무엇이 자동으로 따라오나
- 이펙트·소리·손 위치는 **무기 메시의 소켓**을 따라간다 (2026-11-20 부터).

| 소켓 | 쓰는 곳 | 소켓이 없으면 |
|---|---|---|
| `Muzzle` 총구 | 총구 섬광·탄 궤적·빔·번개·화염 불꽃·레일건 링, 사격 소리 위치 | 무기 표의 `Muzzle Fallback` → 0 이면 메시 앞(+X) 끝 가운데 |
| `BladeTip` 칼끝 | 근접 궤적 리본 | `Blade Tip Fallback` → 0 이면 피벗에서 앞 끝까지의 90% |
| `BladeBase` 칼날 시작 | (예약: 날 전체 효과용) | `Blade Base Fallback` → 0 이면 25% |
| `Grip` 손잡이 | 이 점이 오른손에 오도록 모델을 옮긴다 | 피벗(모델 원점) |
| `SupportHand` 보조 손 | 화염방사기·레일건·지뢰의 왼손 자리 | `DA_VHCharacterVisuals` 의 Left Hand On Weapon |

- 지금 임시 모델 10개에도 같은 소켓을 넣어 두었다(지금 화면과 같은 자리, 전후 차이 0.32cm 이하로 확인).
- 재질 덮어쓰기(`Material Overrides`)는 10종 모두 비어 있다 → **메시에 든 재질이 그대로** 나온다.

## 교체 순서
1. FBX 를 `C:\UnrealProjects\MCPTest\SourceArt\Weapons\Modeler\` 에 넣는다. 파일 이름에 번호가 있어야 한다: `VH-01_Baton.fbx` … `VH-10_ShockMine.fbx` (텍스처는 FBX 옆에).
2. 에디터를 연다(플레이 중이 아닐 때). 아래쪽 **Cmd** 칸에 입력:
   ```
   py "C:/UnrealProjects/MCPTest/Tools/WeaponBuild/weapon_models.py" import_dir "C:/UnrealProjects/MCPTest/SourceArt/Weapons/Modeler"
   ```
   하나만: `py ".../weapon_models.py" import 4 "C:/…/VH-04_Pistol.fbx"`
3. **창 → 출력 로그**에서 `[WeaponModel]` 줄을 읽는다.
   - `재질 칸 [...] (발광으로 바꿈 [...])`: 재질 이름에 `Glow` 가 있는 칸은 분류 발광 재질(`MI_VHW_Glow_근접/원거리/투척/설치`)로 바뀐다.
   - `없음 → 대신 값: [...]`: 그 소켓이 없어서 자동 계산 자리를 쓴다. 화면에서 위치가 맞으면 그대로 둬도 된다.
   - `길이가 기준과 3배 넘게 다름`: 단위가 틀림 → 다시 받거나 `import 번호 파일 scale=100`(미터로 왔을 때).
   - `앞 방향이 +Y 같음`: `import 번호 파일 rot=-90` (또는 90).
4. 무기 전체 점검: `py ".../weapon_models.py" check`
5. 화면으로 확인 (아래 "확인할 것").
6. 마음에 안 들면 되돌리기: `py ".../weapon_models.py" restore 4` 또는 `restore all` → 임시 모델로.
   - 새 모델은 `/Game/VaultHeist/Weapons/Meshes/Modeler/NN_이름/` 에, 임시 모델은 `/Game/VaultHeist/Weapons/Meshes/SM_VHW_*` 그대로 남는다(백업).
   - 처음 바꿀 때의 값은 `Tools/WeaponBuild/weapon_mesh_backup.json` 에 적힌다.
7. 커밋.

## 확인할 것 (게임 레벨 또는 `L_CharPreview` 에서 ▶, Cmd 칸)
| 명령 | 볼 것 |
|---|---|
| `vh.Weapon N` | 오른손이 손잡이를 쥐는가, 총구·칼끝이 앞(커서 방향)을 보는가, 크기가 캐릭터에 비해 맞는가 |
| `vh.WeaponTest N` | 공격 동작·소리·이펙트. 권총·테이저·레일건: 섬광이 **총구**에서. 화염방사기: 불꽃이 **총구**에서, 판정 부채꼴 안. 근접: 리본이 **칼끝**을 따라감 |
| `vh.WeaponTest N slow 0.2` | 느리게 보기 |
| `vh.Cam 470 -16 -125 20` / `vh.Cam off` | 가까이 / 탑뷰 |
| `vh.ShowPickup N 200 0 1` | 바닥에 놓인 모습 |
| `vh.WeaponRefresh` | DA 값을 고친 뒤 다시 붙이기 (플레이 중에도) |
| 숫자로 비교 | `bash Tools/WeaponBuild/dump_all_points.sh 이름` (플레이 중) → `Saved/WeaponBuild/points_이름.json` 에 무기 10종의 손·무기·총구 위치 |

## 문제가 생기면 고칠 칸 (`DA_VHWeaponCatalog` → Weapons → 그 무기)
| 문제 | 고칠 칸 |
|---|---|
| 모델이 옆·뒤를 본다 | Model → **Model Rotation** (Yaw ±90·180) |
| 너무 크다/작다 (단위 문제) | Model → **Model Scale** |
| 탑뷰에서 보기 좋게 크기만 조정 | Held → **Held Scale** (든 모습), Floor → **Floor Scale** (바닥) |
| 칼·봉이 탑뷰에서 선처럼 가늘다 | Held → **Held Thickness** |
| 손이 손잡이에서 어긋난다 | 모델의 `Grip` 소켓 위치(메시 에디터 → 소켓 관리자), 또는 Held → **Grip Offset** |
| 총구 이펙트 위치가 틀리다 | 모델의 `Muzzle` 소켓, 또는 Model → **Muzzle Fallback** |
| 궤적 리본이 칼끝이 아니다 | 모델의 `BladeTip` 소켓, 또는 **Blade Tip Fallback** |
| 왼손 위치 (화염방사기·레일건·지뢰) | 모델의 `SupportHand` 소켓, 또는 `DA_VHCharacterVisuals` 의 Weapon Poses → Left Hand On Weapon |
| 바닥에 놓인 자세 | Floor → **Floor Offset** (테이저건은 Floor Mode = 구상안 그림이라 모델이 안 보인다 → "3D 모델"로) |
| 발광 띠 색이 이상하다 | 메시 에디터에서 그 재질 칸을 `MI_VHW_Glow_*` 로 |

- 소켓은 언리얼에서도 넣을 수 있다: 메시를 더블클릭 → 창 → 소켓 관리자 → 이름(`Muzzle` 등) 정확히.
- 이펙트 크기·색·소리는 그대로다(`DA_VHWeaponCatalog` 의 Weapon Fx, `DA_VHSoundConfig`). 모델을 바꿔도 다시 할 일 없음.
- HUD 아이콘·바닥 그림은 구상안 그림에서 만든 것이라 모델과 따로다(`Tools/WeaponBuild/render_icons.ps1`).
