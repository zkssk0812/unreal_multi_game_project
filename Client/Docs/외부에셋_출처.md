### 애니메이션 → 반동 곡선만 (에셋은 가져오지 않음)
- `MM_Pistol_Fire`, `MM_Rifle_Fire`, `MM_Rifle_GrenadeToss` 에서 오른손·허리 움직임을 첫 프레임 기준 숫자로 뽑음 → `Tools/External/lyra_recoil.json` (`lyra_export.py recoil`)
- 이유: Lyra 동작을 몽타주로 통째로 쓰면 팔을 동작이 움직여 우리 무기 손 위치(코드 IK)가 깨진다. 곡선을 키워서 우리 키 프레임에 넣음(`setup_character_data.py ranged`): 권총 0.27초·총구 24°, 테이저 0.33초·13°, 레일건 0.6초·19° + 뒤로 9cm
### 나이아가라 → 가져오지 않음 (참고만)
- 후보: 총구 섬광(`NS_WeaponFire_MuzzleFlash_Rifle`), 탄 궤적(`NS_WeaponFire_Tracer`), 몸 피격(`NS_ImactSparksCharacter`), 콘크리트 피격, 수류탄 폭발(`NS_Grenade_Explosion`)
- 의존 크기(`lyra_export.py deps`, 단단한 참조만): 5개 290MB → 3개로 줄여도 **206MB** (총구 연기 플립북 `SmokeSwirl_3_Flipbook_CHANNELPACK` 146MB, 폭발 플립북 32MB 등) + Lyra 전용 무기 트리거·데이터 채널 모듈(`NM_WeaponTrigger`, `NM_ImpactReadDataChannel`)에 묶여 있어 우리 코드에서 그대로 쓰기 어려움
- 결정(Claude, 사용자 확인 필요): 프로젝트 크기를 지키려고 가져오지 않고, 엔진 기본 나이아가라·우리 도형 재질로 만듦 (계획표의 대안)
