# 정호님께 — 문 F 거리 맞춤 참고 (2026-11-25, 급하지 않음)

정호님, 기획자 확인 결과를 클라이언트에 반영하면서 문을 F로 여닫는 거리를 금고·상자 상호작용 거리와 같게 맞췄습니다.
서버 코드는 건드리지 않았고, 아래는 확인한 내용과 **선택 사항**인 제안 하나입니다.

## 서버에서 확인한 거리 (팀 저장소 `Server/`, 커밋 `b968b48` 기준, 읽기만)

| 대상 | 서버 값 | 재는 방법 (`GameWorld::InRange`, 바닥 2D 거리) | 코드 위치 |
|---|---|---|---|
| 금고 | `WorkRangeCm` = **130cm** | 금고 가운데(`interactPos`)에서 130 | `WorldItems.cpp` 35줄 |
| 상자 (무기·환금) | `WorkRangeCm + BoxRadiusCm` = 130 + 50 = **180cm** | 상자 가운데에서 180 = 상자 겉에서 130 | `GameWorld.cpp` 176줄 |
| 문 | `DoorRangeCm` = **150cm** | 문 가운데에서 150 | `WorldDoors.cpp` 32줄 |
| (참고) 바닥 아이템 줍기 | `PickupRangeCm` = 300cm | 아이템 가운데에서 300 | `GameWorld.cpp` 181줄 |

## 클라이언트에서 바꾼 것
- F로 문을 **고르는** 거리(문 테두리가 빛나고 "[F] 문 열기/닫기" 안내가 뜨는 거리)를 문 가운데에서 **130cm**로 맞췄습니다 (예전 140cm). 금고와 같은 `WorkRangeCm` 값입니다.
- 서버 문 판정 150cm보다 안쪽이라, 위치 차이(최대 50ms)가 있어도 `OutOfRange` 거절이 나지 않습니다. 실제 시험(팀 서버, 봇)에서 115cm에서 F → 바로 열림/닫힘, 거절 없음을 확인했습니다.

## 선택 사항 (바꾸지 않으셔도 동작에는 문제 없습니다)
- 규칙 문서상 "문 거리 = 금고·상자 작업 거리"로 맞추고 싶으시면 `DoorRangeCm`을 `WorkRangeCm`(130)으로 두시는 방법이 있습니다.
  다만 그러면 서버 판정과 클라 고르는 거리가 똑같아져 위치 차이 여유가 없어지므로, 그때는 클라 쪽을 120cm 정도로 낮추겠습니다. 지금처럼 서버 150 / 클라 130이 더 안전하다고 생각합니다.

## 같이 바뀐 클라 표시 (서버 영향 없음, 참고)
- 문 표시(바닥 띠·벽 위 표시·미니맵)에서 **열림/닫힘 색 구분을 없앴습니다** — 미니맵의 문 색으로 다른 사람이 문을 열었는지(위치) 알 수 없게. 잠긴 바깥 문 2곳만 빨강입니다.
- 열린 문 너머 시야는 이제 "문틈 부채꼴 ∩ 내가 바라보는 방향(마우스) 90°"만 보이고, 거리 제한 없이 벽·닫힌 문에 막힐 때까지(열린 문을 지나 그 너머 방까지) 보입니다. 화면에 보이는 것만 바꾸므로 서버 판정과는 무관합니다.
