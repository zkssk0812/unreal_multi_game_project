# 정호님께 — 팀 저장소 서버(11-22 23시 커밋) 클라 맞춤 결과와 확인 부탁 (2026-11-22)

정호님, 11-22 밤에 올려 주신 서버 커밋(`186f8a0` 레일건, `f6efc54` 사제 테이저건, `d83afde` 반납 경고, `ee24075`·`9aae6a0` protocol.h 이동)에 클라이언트를 맞췄습니다. 서버 코드는 손대지 않았고 팀 저장소 `Server/`를 그대로 빌드(Release x64, 경고 0)해서 시험했습니다. `ContentTests` 168개도 모두 통과했습니다.

## 클라에서 바꾼 것
- 클라 `protocol.h` 사본을 `Common/Protocol/protocol.h`와 같게 맞췄습니다(다른 점은 `UseSkill` 주석, `ES_RAILGUN_LOCK` 주석, `ES_TASER_READY = 1u << 21` 추가 — 3곳). 클라 게임 레벨 맵 버전도 10으로 맞춰서 "맵 버전 다름" 경고가 이제 뜨지 않습니다.
- 레일건: 클릭하면 바로 `AttackStart`를 보내고, 제 `SC_FIRE`를 받으면 `AttackStop`을 보냅니다(클릭 한 번에 한 발). 충전 연출 1초와 빔은 `SC_FIRE` 받은 시각 기준이라 다른 플레이어 화면에서도 보이고, 충전 중에 쓰러지면 연출을 끊습니다.
- 사제 테이저건: Q = `UseSkill`(들기/집어넣기), 든 채 공격 키 = `AttackStart`. 손 모양은 `SC_SKILL`과 `ES_TASER_READY`를 따르고, 다른 플레이어가 들면 그 사람 손에도 보입니다.
- 반납 지점 빨강은 서버 `ES_WARNING` 비트를 그대로 씁니다(켜지는 순간 남은 시간 5초로 맞춤).

## 시험 결과 (로컬 팀 서버, 봇 2명)
- 레일건: 클릭 → `SC_FIRE`까지 33ms, 빔은 클릭 1,050ms 뒤(서버 첫 판정 시각). 과녁 HP 100 → 1(가시회생). 충전 중 경비원에게 쓰러짐 → 양쪽 화면 모두 연출 취소, 빔 없음.
- 테이저: Q 들기(Active) → Q 넣기(End, 쿨타임 0) → Q 들기 → 공격 키(Cast, 쿨타임 29.7초) → 과녁 경직 약 2초. 과녁 화면에서 든 사람 손 무기가 테이저(7)로 바뀌었다가 돌아오는 것 확인.
- 반납 경고 켜짐 → 5.01초 뒤 반납 지점 사라짐.

## 확인 부탁드릴 것
1. **무기가 하나뿐일 때 테이저를 든 채 휠**: `SwitchWeapon`이 다른 칸이 비어 거절되면 `HolsterTaser`도 불리지 않아 테이저를 계속 듭니다. 의도하신 동작인지요? (클라는 서버 결과를 그대로 보여 줍니다. 이때는 Q로 집어넣을 수 있습니다.)
2. **레일건을 꾹 누르고 있을 때**: 서버는 잠금 2초가 끝나면 이어서 쏘지만, 클라는 클릭 한 번 = 한 발로 `SC_FIRE` 직후 `AttackStop`을 보냅니다(예전 클라 방식 유지). 이대로 괜찮을까요?
3. 레일건 충전 중 **경직**은 서버에서 발사를 막지 않는 것으로 보았습니다(쓰러짐만 취소). 클라도 그렇게 맞췄습니다.
