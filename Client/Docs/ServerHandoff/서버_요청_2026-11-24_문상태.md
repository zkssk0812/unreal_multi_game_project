# 정호님께 — 문 열림 상태 (2026-11-24, 클라 김윤기)

정호님, 기획이 "문을 F로 열고 닫기 + 열린 문 너머 일부만 보이는 시야"로 바뀌어 클라에 먼저 넣었습니다.
지금 서버·프로토콜에는 문 상태가 없어서 **각 클라가 자기 화면에서만** 문을 열고 닫습니다. 서버 코드는 건드리지 않았습니다.
나중에 서버에 문 상태를 넣으실 때 참고하시라고 클라 쪽 구조와 바라는 점을 정리했습니다. 급한 요청은 아닙니다.

## 지금 클라 동작
- 문 39개 = 서버 맵 `colliders.static` 의 `above_door` 39곳(문 id = 그 collider id, 예 `wall_109`). 잠긴 바깥 문 2곳(현관 `wall_260`, 냉동실 `wall_134`)은 안 열립니다.
- 처음엔 모두 닫힘. 문 앞에서 F → 열기/닫기 (상자·아이템·금고·반납이 F 대상이면 그쪽이 먼저).
- 닫힌 문은 **내 캐릭터만** 클라에서 막습니다(이동은 클라 권위라 결과적으로 서버 위치도 막힘). 서버 판정·다른 플레이어·경비원은 그대로라, 다른 사람 화면에서는 같은 문이 열려 있거나 닫혀 있을 수 있습니다.
- 열린 문 너머는 내 위치에서 문틈 양 끝을 지나는 부채꼴만 보이게 했습니다(보이는 것만, 판정 영향 없음).

## 서버에 문 상태가 생긴다면 (제안, 정호님 판단에 맡깁니다)
- `CS_ACTION` 의 InteractBegin 에 문 id 를 넣는 방식이든 새 패킷이든 괜찮습니다. 클라는 "F → 요청만 보내고, 서버 메시지를 받으면 상태 적용"으로 바꾸기만 하면 됩니다(`IVHDoorStateSource` 하나 추가).
- 필요한 것: 문 id(맵 collider id 또는 번호), 열림/닫힘, 게임 시작 때 전체 상태(또는 모두 닫힘 약속), 바뀔 때 방 전원에게 알림.
- 닫힌 문을 서버 이동·시야·총알 판정에도 쓰실지(지금은 `blocks_move: false`)는 기획과 함께 정해 주시면 클라도 맞추겠습니다.
- 경비원이 문을 여는지, 잠긴 방이 생기는지도 정해지면 알려 주세요.
