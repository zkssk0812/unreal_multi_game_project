# PvP 전환 서버 요청서 v1 (초안, 2026-11-06)

정호님, 안녕하세요. 클라이언트 담당 김윤기입니다.
팀에서 게임을 **PvE 협동 → PvP 경쟁**으로 바꾸기로 해서, 서버에서 바꿔 주셔야 할 부분을 정리했습니다.
확정 규칙 전체는 `Docs/PvP_규칙_v1.md`에 있습니다. 클라이언트는 우선 가짜 서버(Mock, 클라이언트 로컬 판정)로 먼저 만들고 시험하고 있으며, 서버 코드는 손대지 않았습니다.

아래 패킷 모양은 **제안일 뿐**이고, 이름·구조는 정호님께서 편하신 대로 정해 주시면 클라이언트를 맞추겠습니다.
[미정]이라고 적힌 항목은 팀에서 아직 정하지 않은 것이라, 정해지면 다시 말씀드리겠습니다.

## 1. 규칙 요약 (서버 판정에 필요한 것만)
- 제한시간 8분, 종료 시 **반납 금액이 가장 많은 사람이 승리**. 들고만 있는 아이템은 점수 아님. 탈출구 없음.
- HP 100(자연 회복 없음), SP 100(자연 회복, 0이 되면 가득 찰 때까지 달리기·구르기 불가). **공격은 SP를 쓰지 않음.**
- 사망
  - 다른 플레이어에게: 들고 있던 환금 아이템은 그 자리에 떨어짐, 무기 소멸(삼단봉 제외), 반납 금액 10% 소멸, 5초 뒤 리스폰
  - 경비원에게: 환금 아이템·무기 소멸(삼단봉 제외), 반납 금액 40% 소멸, 10초 뒤 리스폰
  - 보물은 누구에게 죽든 그 자리에 떨어짐
  - 리스폰: 처음 시작 위치, HP·SP 최대, 상태이상 삭제, 스킬 쿨타임 초기화, 삼단봉 보유, 5초 무적
- 금고: 동시에 1개만 존재(기존 후보 10곳 중). 열면 보물 1개 + 전체 공지. 보물이 반납되면 새 금고 1개(직전 위치 제외). 진행도 유지, 동시 1명. 여는 시간 [미정, 임시 60초]
- 반납지점: 2곳, 60초마다 다른 곳으로 이동(나머지 기존 규칙)
- 무게·숨는 곳·창고 감금/구출·탈출구·소리로 경비원 유인 삭제 (소리 자체는 유지)
- 무기 최대 2개(휠 교체, 꾹 누르면 공격): 삼단봉(영구, 10, DPS 30) / 테이저건(1회, 1 + 경직 2초) / 권총(12회, 10, 초당 4발) / 화염방사기(90회, 2, 초당 30발) / 도검(영구, 25, DPS 50)
- 상자(공격으로 부숨, 확률로 무기), 회복약 소10/중30/대50(줍는 즉시 사용)
- 스킬 1개 선택(쿨 30초): 사제 테이저건 / 끈끈이 투척 / 카멜레온 은신
- 퍽 3개 선택: 방탄조끼, 기사회생, 유용한 도구, 운동화, 보물탐색, 로봇탐지, 생체감지
- 경비원: HP 200, 0이면 5초 자가 수리(무적·정지) 후 회복, 플레이어 속도 70%로 탐색, 발견 시 기관총(10, 초당 10발, 60도 부채꼴 랜덤), 회전 매우 느림. 타게팅: 먼저 발견한 사람 → 시야에 둘이면 가까운 사람 → 타겟 아닌 사람에게 맞으면 그 사람으로

## 1-1. 클라이언트에서 이미 빠진 기능 (알려 드리는 내용)
PvP 규칙에 따라 클라이언트에서 아래 기능을 **삭제**했습니다. (PvE 버전은 저희 저장소 태그 `pve-final`에 그대로 남아 있습니다.)
- **숨는 곳**: 옷장(숨는 곳) 오브젝트와 숨기/나오기 동작
- **창고 감금·구출**: 창고 문 오브젝트, 잡힘·갇힘·구출 상태
- **탈출구**: 탈출구 오브젝트와 탈출 판정, 목표 반납 가치
- **무게**: 아이템 무게, 소지 개수·무게 한도, 무게에 따른 속도·스테미나 변화
- **경직 시 보물 떨어뜨림**: 경직되어도 아이템을 떨어뜨리지 않습니다. 환금 아이템은 **사망할 때만** 떨어지거나 사라집니다.

그래서 지금 v2.1 서버에 접속하면 아래처럼 됩니다.
- `SC_HIDE`, `SC_CAPTURED`, `SC_RELEASED`, `SC_JAILED`, `SC_EXIT_OPENED`, `SC_ESCAPED`를 받아도 **로그만 남기고 무시**합니다(연결은 끊지 않습니다). 화면에는 잡힘·탈출 장면이 나오지 않습니다.
- 클라이언트는 숨는 곳·창고 문·탈출구에 상호작용 요청을 보내지 않습니다.
- 맵의 창고 벽·탈출구 기둥·바닥은 맵 구조라 그대로 두었습니다. 서버 맵 파일(`mansion_1f_server.json`)의 `hiding_spots`, 창고·탈출구 항목은 서버에서 쓰지 않으셔도 됩니다.

## 1-2. 클라이언트 진행 상황 (2026-11-06)
가짜 서버(Mock, 클라이언트 로컬 판정)에서 아래 R1~R10에 해당하는 규칙을 먼저 만들어 시험을 마쳤습니다. 서버 구현하실 때 동작 기준으로 참고하실 수 있도록 정리합니다.
- 삼단봉: 꾹 누르는 동안 누르는 즉시 1회, 이후 1/3초마다 1회, 시선 방향 1.5m·120° 부채꼴 안 대상마다 10 대미지 (사거리·각도는 저희 가정값입니다)
- 사망 처리 순서: 상태 사망 → 보물은 항상 그 자리에 드롭, 그 밖의 환금 아이템은 PvP면 드롭·경비원이면 소멸 → 삼단봉 외 무기 소멸 → 반납 금액 손실(10%/40%, 소수점 내림) → 5초/10초 뒤 처음 시작 위치에서 리스폰(HP·SP 최대, 5초 무적)
- 리스폰 무적 중에 공격하면 무적이 풀리게 해 두었습니다(팀에서 아직 확정 전이라 설정값입니다).
- 금고: 동시에 1개, 보물이 반납되면 직전 위치를 뺀 후보에서 새 금고 1개
- 순위: 반납 금액이 같으면 같은 등수(임시)
- 실서버(v2.1)에 접속하면 위 PvP 규칙은 동작하지 않고, 서버의 PvE 판정이 그대로 진행됩니다(클라이언트는 PvE 전용 패킷을 무시).

## 2. 지금 v2.1로 안 되는 것 (클라이언트에서 확인한 내용)
- 스냅샷에 HP·SP·보호막 값이 없습니다.
- 피해량·처치 이벤트가 없고, 서버의 의적 공격 판정이 경비원만 대상입니다 (`GameWorld.cpp:681-689`).
- 사망·리스폰·의적 무적을 나타낼 방법이 없고, 상태 비트 16개가 모두 사용 중이라 빈 비트가 없습니다.
- `SC_TREASURE.delivered_value`가 팀 합계라 개인별 반납 금액(순위·사망 손실)을 표현할 수 없습니다.
- 무기 id·남은 횟수, 무기 교체, 꾹 누르기(연사 시작/끝) 행동이 없습니다.
- 상자·무기·회복약·끈끈이 함정 엔티티 종류가 없습니다.
- 방 단계에 스킬 선택 필드가 없고, `UseSkill`은 항상 `NotAvailable`로 거절됩니다.
- `SC_GAME_LOAD.safe_slots`가 고정 5칸입니다(금고 1개 순환과 맞지 않음).
- `PlayerResult`에 순위·처치·사망 수가 없고, `escaped`·`jailed`·`guard_stuns`는 의미가 없어집니다.
- 퍽은 ID 1~7로 쓰면 지금 검사(1~8)를 통과합니다. 효과는 게임 코드에 아직 없습니다.

## 4. 여쭤보고 싶은 점
1. 위 R1~R10 중 먼저 하기 쉬운 순서가 있으시면 알려 주세요. 클라이언트는 그 순서대로 실서버 연결을 맞추겠습니다.
2. 상태 비트가 꽉 차 있는데, `state`를 u32로 늘리는 것과 사망·무적을 이벤트로만 보내는 것 중 어느 쪽이 편하신지요.
3. 프로토콜 버전을 3.0으로 올리실 계획이신지요(클라이언트 `PROTOCOL_VERSION`도 같이 맞추겠습니다).

바쁘신데 긴 글 읽어 주셔서 감사합니다. 클라이언트 쪽 PvP 시험 결과가 나오면 다시 공유드리겠습니다.
