# 정호님께 보낼 메일 초안 (2026-11-17 v2, 새 캐릭터 모델)

**제목**: [털어라! 금고!] 새 캐릭터 모델 적용 클라이언트(11-17 v2) 전달드립니다

정호님, 안녕하세요. 클라이언트 맡고 있는 윤기입니다.

오늘 낮에 보내드린 클라이언트에 이어서, 모델러분께 받은 새 캐릭터 모델을 적용한 버전을 다시 보내드립니다.
낮에 보내드린 버전(VaultHeist_Client_2026-11-17)은 지우셔도 됩니다.
실행 방법은 같습니다. 압축을 푸신 뒤 VaultHeist.exe를 실행하시고, 메인화면 아래 주소칸에 서버 주소(같은 PC면 127.0.0.1:9000)를 넣고 [실서버로 전환]을 누르시면 됩니다. 자세한 방법과 조작키는 폴더 안 "먼저_읽어주세요.txt"에 적어 두었습니다.

**이번 버전에서 바뀐 것 (낮 버전 대비)**
- 모델러 캐릭터(의적) 모델 적용: 내 캐릭터와 다른 플레이어 모두 새 모델이고, 걷기·달리기·구르기·쓰러짐 동작도 맞췄습니다.
- 로봇 경비원 모델 적용: 기관총을 들고 순찰·추적·사격 자세가 나옵니다.
- 플레이어 구분 색 링: 의적 모델이 하나라 발밑에 색 링(빨강·파랑·노랑)을 깔았습니다. 모든 화면에서 같은 사람은 같은 색입니다.
- 무기 쥐는 모양: 근접 무기는 주먹으로 감싸 쥐고, 총은 손잡이 아래·총구 앞으로 세워 듭니다.
- 근접 무기 3종(삼단봉·검·빔소드): 칼날을 세워 조준 방향으로 약 40° 기울여 들고, 공격은 오른쪽에서 왼쪽으로 수평 베기입니다(궤적 이펙트도 같은 방향). 동작 길이는 서버 공격 간격 안으로 맞췄습니다.

규칙 판정은 모두 서버 값 그대로이고, 클라이언트는 표시만 바꿨습니다. 저희 쪽 서버 사본(feature/pvpve-v3, 커밋 1b53272)에 패키징한 클라이언트를 붙여서 새 모델·색 링·무기 쥐기·베기·구르기·쓰러짐이 나오는 것을 확인했습니다.

**확인 부탁드릴 것**
1. 서버 맵 버전: 이 클라이언트는 여전히 맵 버전 **2**에 맞춰져 있습니다. 서버를 켜셨을 때 첫 줄이 "[Map] mansion_1f v2: 방 35 …"로 나오는지 봐 주시겠어요? 혹시 맵이 **v10**으로 바뀌었다면 알려 주시면, 배치를 맞춰서 다시 빌드해 드리겠습니다.
2. 플레이해 보시고 이상한 점이나 서버와 다르게 보이는 부분이 있으면 편하게 알려 주세요. 가능하시면 푼 폴더의 MCPTest\Saved\Logs\MCPTest.log 파일을 같이 보내 주시면 원인을 찾는 데 큰 도움이 됩니다.

**알려진 문제**
- 화염방사기를 빠르게 여러 번 클릭하면 불꽃 이펙트가 꺼지지 않고 남을 수 있습니다. 클라이언트 표시 문제(서버 판정과는 무관)라 다음 버전에서 고치겠습니다.

서명이 없는 개발용 빌드라 실행할 때 Windows 보호 창이 뜰 수 있습니다. [추가 정보] → [실행]을 누르시면 되고, 방화벽 창이 뜨면 [허용]을 눌러 주세요. 스마트 앱 컨트롤 때문에 막히면 Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정을 확인해 주세요.
