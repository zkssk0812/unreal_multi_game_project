# 레일건 충전 표시 요청 (2026-11-20, 급하지 않음)

정호님, 클라이언트 김윤기입니다. 레일건에 "1초 충전 → 발사" 연출을 넣으면서 서버 코드를 읽어 봤는데, 한 가지 부탁드릴 것이 있어 정리했습니다. **지금 서버는 그대로 두셔도 게임은 정상으로 돌아갑니다.**

## 지금 서버 동작 (커밋 1b53272 기준으로 확인한 것)
- `CS_ACTION AttackStart` 를 받으면 `attackHeld = true`, 다음 틱 `UpdateFiring` → `FireWeapon` 에서 **바로 발사**합니다 (충전·대기 시간 없음).
- 레일건 쿨다운(`intervalMs` 1000)은 **발사 순간부터** 셉니다 (`nextFireMs += intervalMs`). 발사와 동시에 `RailgunLock` 1초, 0·200·…·1000ms 에 판정 6번.
- 입력은 틱마다 모아서 처리하므로, 같은 틱 안에 AttackStart·AttackStop 이 같이 들어가면 발사되지 않습니다.

## 클라이언트에서 한 것
- 좌클릭 → 클라이언트가 1초 동안 충전 연출(소리·총구 빛) → 그때의 커서 방향으로 `AttackStart` → `SC_FIRE` 를 받으면 `AttackStop`.
- 충전 중 무기 교체·쓰러짐·경직이면 클라이언트가 취소하고 아무것도 보내지 않습니다.
- 실서버(V3b)에서 확인: 클릭 → 1005ms 뒤 신호 → 42ms 뒤 `SC_FIRE` → 0.2초 간격 피해 6번 정상.

## 문제: 다른 플레이어 화면에는 충전이 보이지 않습니다
- 충전 중에는 서버에 아무것도 보내지 않으므로, 스냅샷의 상태 비트(`ES_ATTACKING` 등)에도 나타나지 않습니다.
- 그래서 맞는 사람은 1초 전에 예고를 볼 수 없고, 갑자기 빔이 나옵니다 (레일건은 벽을 뚫고 120 피해라 예고가 있으면 피할 기회가 생깁니다).

## 부탁드리는 것 (둘 중 하나)
1. **서버가 충전을 맡는 방법 (추천)**
   - 레일건 `AttackStart` 를 받으면 바로 쏘지 않고 상태 비트 `ES_RAILGUN_CHARGE`(새 비트) 를 켜고, `RailgunChargeMs`(1000) 뒤에 그때의 `yaw` 로 발사.
   - 충전 중 무기 교체·쓰러짐·경직이면 취소하고 비트를 끔. 충전 중 이동은 그대로, 회전은 계속 받음(발사 순간 방향).
   - 장점: 서버 권위 그대로, 모든 클라이언트가 스냅샷 비트로 충전을 같이 봄, 핑에 따라 1초가 달라지지 않음.
   - 이렇게 바뀌면 클라이언트는 "1초 기다렸다 보내기"를 끄고(`DA_VHWeaponCatalog` 의 `RailgunChargeSeconds` 를 0) 비트를 보고 연출만 하겠습니다.
2. **클라가 알리기만 하는 방법**
   - `CS_ACTION` 에 새 행동 `ChargeStart` / `ChargeCancel` 을 두고, 서버는 받은 사람에게 `ES_RAILGUN_CHARGE` 비트만 켜고 끔 (판정에는 쓰지 않음).

## 필요한 값
| 값 | 어디 | 이유 |
|---|---|---|
| `ES_RAILGUN_CHARGE` (상태 비트 하나, 예: `1u << 비어 있는 자리`) | `SC_SNAPSHOT` 플레이어 상태 | 다른 플레이어 화면에 충전 소리·빛을 보여 주기 |
| `RailgunChargeMs = 1000` | `GameData.h` (1번 방법일 때) | 충전 시간을 서버가 정하도록 |
