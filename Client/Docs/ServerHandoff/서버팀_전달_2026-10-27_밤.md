## 1. 버전 불일치 원인 (서버 쪽 문제 아님)
- 서버 로그(`GameServer_20261027_191315`): `프로토콜 버전 불일치 0x00010000 (서버 0x00020001)` ×5 → **클라가 v1.0 을 보냄**.
- 클라 저장소 `client/menu-ui` 의 `protocol.h` 는 서버 `Shared/Protocol/protocol.h`·카톡 파일과 **내용이 똑같은 v2.1** (오늘 서버 파일을 그대로 다시 복사, 줄바꿈만 다름). v2.1 반영은 16:31에 push됨.
- 즉 **v2.1 이전에 빌드한 클라 DLL이 실행된 것**. 언리얼은 소스만 바뀌면 "다시 빌드?"를 묻지 않고 예전 DLL을 그대로 쓴다.
- "vh.UseServer 명령이 없다"도 같은 원인(옛 DLL에는 명령이 없음). 또 예전 클라는 ▶ 플레이를 누른 뒤에만 이 명령이 생겼다 → **지금은 플레이 전에도 됨**.

## 2. 최신 클라 받는 법
1. GitHub `LeeJuneWu/project_Unreal_Engine5.8` → 브랜치 **`client/menu-ui`** 받기(pull 또는 ZIP).
2. **에디터를 끄고 프로젝트 폴더의 `Binaries` 폴더 삭제** (옛 DLL 제거).
3. `MCPTest.uproject` 열기 → "모듈을 다시 빌드하시겠습니까?" → **예**.
4. ▶ 플레이 → 메인화면 아래 **`클라 프로토콜 v2.1 (0x00020001)`** 이 보이면 성공.

## 3. 실서버 전환 (설정 파일 안 고침, 기본은 가짜 서버)
