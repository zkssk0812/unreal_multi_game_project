# 서버 팀원 전달 (2026-10-27, 클라 v2.1 반영 후)

클라가 서버 저장소(Project_Rob, 2026-10-27 사본)를 **코드 수정 없이** 우리 PC에서 빌드·실행하고 우리 배치 데이터로 접속~탈출까지 시험한 결과입니다.
서버 빌드: VS 2026(v143) Release x64 성공, `ContentTests` 113개 통과.

## 1. 내일 시험 전에 서버 쪽에서 해 주면 좋은 것
| # | 내용 | 이유 |
|---|---|---|
| 1 | **배치 적용**: `fbx_to_map.py --layout Docs/ServerHandoff/mansion_1f_layout.json` | 클라 레벨과 같은 금고·숨는 곳·창고·탈출구. 오늘 클라가 사본에서 적용해 보니 서버 엔티티와 클라 오브젝트가 **11곳 모두 0cm로 일치** |
| 2 | 변환 뒤 `floors`에 **`floor_exit`(x 9778~10180, y −4685~−4305)를 다시 넣기** (`fbx_to_map.py` 가 FBX에 없는 바닥을 지움) | 없으면 서쪽 옆문 밖 탈출 구역이 걸을 수 없는 칸 → 탈출 불가. 오늘은 사본 맵에 손으로 넣고 탈출 성공 확인 |
| 3 | **보물 10종 값 교체**: `GameData::TreasureTypes` ← `Docs/ServerHandoff/treasure_types.json` (**번호 대응: 클라 id 0~9 = 서버 1~10**) | 지금 서버는 임시값(예: 4번 황금 왕관 3kg 2,900$). 클라는 `type_id − 1` 로 이름을 보여 주는데 가치·무게가 달라 HUD와 반납 가치가 어긋남 |
| 4 | 맵 `meta.version` 을 **2** 로 유지 | 클라가 `SC_GAME_LOAD.map_version` 이 2가 아니면 "배치가 다를 수 있음" 알림 |

## 2. 오늘 확인된 것 (서버 v2.1 ↔ 클라)
- 로그인·방 목록·방 만들기·입장·캐릭터·퍽·준비·로드·시작·결과·CS_RETURN·자동 로비 복귀
- CS_MOVE 20Hz / SC_SNAPSHOT 20Hz, 두 클라 서로 위치 보임
- 금고 30초 열기, 열린 금고 즉시 줍기, 반납(가운데 100cm), 팀 가치 → SC_EXIT_OPENED, 탈출 구역 → SC_ESCAPED, 숨기/나오기, 경비원 포획·운반·감금, 반납지점 60초 교체
- 경비원 AI가 우리 배치에서 정상 순찰·추격 (오히려 강해서 혼자 금고 30초 여는 동안 자주 잡힘 → 시야 15m·45° 조정 검토 요청)

## 3. 질문·확인 요청
1. **상호작용 거리 기준**: 금고 등은 `interact_pos`(앞면 115cm)에서 150cm 원, 클라 안내는 "상자 가장자리 150cm". 금고 옆·뒤에서 누르면 서버가 OutOfRange. 서버도 상자 기준으로 바꿀지, 클라가 `interact_pos` 기준으로 맞출지?
2. **즉시 상호작용 응답**: 열린 금고 줍기·떨어진 보물·반납은 성공 시 `SC_INTERACT` 없이 `SC_TREASURE` 만 온다. 클라는 "보낸 요청 + 내 보물 개수 변화"로 성공을 판단 중. 명시적 성공 이벤트(예: `SC_INTERACT Complete` duration 0)를 보내 줄 수 있는지?
3. 서버는 마지막 `CS_MOVE` 위치로 거리를 잰다 → 클라는 `CS_ACTION(InteractBegin)` 직전에 `CS_MOVE` 를 한 번 더 보낸다(같은 틱 안에서 순서대로 처리되는지 확인 부탁).
4. **보물 type_id 번호**: 1~10이 맞는지(클라는 `type_id − 1` 로 표를 찾음). 반납지점 `type_id` = 방 배열 위치(0부터)로 이해함.
5. 결과 후 대기실 복귀(CS_RETURN target)는 v2.1에 없어 클라는 [로비로]만 표시. 추가 계획이 있으면 알려 주세요.
6. 전적·방 옵션(맵·난이도)도 v2.1에 없어 화면에서 숨김.
7. 위치 z: 클라는 **발 위치(캡슐 아래)**를 보낸다(서버 문서의 "발 높이 기준 시야" 가정과 맞춤).
8. 같은 PC에서 GameServer.exe 를 처음 실행하면 Windows 방화벽 허용 창이 뜬다. 다른 PC에서 접속하려면 서버 PC에서 9000 포트 허용 필요.
