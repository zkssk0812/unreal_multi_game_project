### 0-1. 카메라와 조작 ⟪기획 변경⟫
- **카메라는 탑뷰** [팀 결정]: 위에서 내려다보는 고정 카메라, 회전 없음. 각도·거리는 데이터로 조절.
- ⟪기획 변경 2026-10-26: 팀 결정 — 이동 기준 변경⟫ 게임_시스템.pdf 4장의 "W = 월드 x축 고정" 방식을 대체한다.
  - 캐릭터의 **"앞" = 항상 마우스 커서 방향**. 캐릭터는 커서가 가리키는 바닥 지점을 계속 바라보고, 손전등도 그 방향을 비춘다.
  - **WASD는 캐릭터가 바라보는 방향(커서 방향) 기준**: W 커서 쪽(앞) / S 커서 반대쪽(뒤) / A 바라보는 방향의 왼쪽 / D 오른쪽. 대각선도 같은 기준으로 합친다.
  - 움직이는 동안에도 계속 커서를 바라본다(예: S = 커서 쪽을 비추며 뒷걸음질). 손전등이 꺼져 있어도 같다.
  - **몸 전체가 커서를 바라본다** [가정]. 이전의 "하체는 이동 방향, 상체만 마우스, 좌우 90° 제한"은 없앴다.
  - 커서가 캐릭터 **1m 안**이면 마지막 방향 유지(흔들림 방지) [가정]. 몸이 커서 쪽으로 도는 속도는 거의 즉시(1800°/s) [가정, 데이터로 조절].
  - 뒤·옆 이동도 앞과 **같은 속도** [가정] — 방향별 속도 배율(앞·뒤·옆)을 데이터로 바꿀 수 있다.
  - 경직·숨음·잡힘·갇힘 중에는 방향을 바꾸지 않는다.
  - 이전: ~~W가 화면 위쪽, 이동은 월드 축 기준(W = x+, S = x−, A = y−, D = y+), 하체는 이동 방향으로 회전, 시선은 몸통 기준 좌우 90°까지만~~

### 0-4. 두 가지 상호작용 방식
| 방식 | 사용법 | 쓰는 곳 |
|---|---|---|
| **길게 누르기(홀드)** | 키를 누르고 있는 동안 진행 바가 차고, 다 차면 완료 | 금고, 창고 문 |
| **짧게 누르기(탭)** | 한 번 누르면 짧은 동작(0.5초) 후 바로 완료 | 보물 줍기, **보물 반납**, 숨기/나오기 |

⟪기획 변경⟫ 탈출구는 상호작용 대상이 아니다(열기·탈출 모두 자동). 이전: ~~탈출구 길게 누르기 10초, 탈출 짧게 누르기~~

### 0-5. 길게 누르기 중 규칙
- 상호작용 중에는 **제자리에 서 있는다**(이동·달리기·구르기 불가). 서버 상태 `ES_INTERACTING`.
- 아래 경우 **즉시 취소**: 키를 뗌 / **이동·Space(구르기)·공격 입력** / 경비원에게 잡힘 / **경직** / 대상 상태가 바뀜.
- 취소 시 진행도 처리는 오브젝트마다 다르다(아래 표).
- 오브젝트 하나에 **동시에 1명만** 상호작용 가능. 이미 누가 쓰는 중이면 서버가 거절(`TargetBusy`).

### 0-6. 서버 연동 (Claude Code 참고)
- 누르는 순간: `C_ACTION { action = InteractBegin, target_entity_id }` / 떼거나 취소: `C_ACTION { action = InteractCancel }`
- 서버 응답: `SC_INTERACT { state = Begin/Cancel/Complete, start_server_time_ms, duration_ms }`
- 거절: `SC_ACTION_REJECT { reason = ... }`
- 서버가 아직 게임 로직 미구현이므로, **클라이언트(로컬 판정)에서 같은 규칙으로 먼저 구현**하고 필요한 패킷 추가·변경은 작업 보고서에 정리한다.

## 11. 소리 [기획 PDF 8장]

| 동작 | 소리 반경 | 신호 간격 |
|---|---|---|
| 걷기 | 0m | 0.5초 |
| 달리기 | 12m | 0.2초 |
| 구르기 | 15m | 구르는 동안 계속 |
| 공격(빗나감) | 5m | 1번 |
| 공격(적중) | 20m | 1번 |
| 보물 소지 | 개당 +2m, 최종 반경 ×1.1 | – |

- 계산: `(동작 기본 반경 + 2m × 보물 수) × 1.1`. 예) 보물 2개 들고 달리기 = (12 + 4) × 1.1 = **17.6m**
- "신호 간격"은 실제 소리가 들리는 간격이 아니라 **경비원이 탐지할 수 있게 신호를 보내는 간격**이다 [기획].
- 소리는 벽과 관계없이 들린다. 경비원 NPC는 마지막으로 들은 소리 위치로 걸어간다 [기획 8-1, 경비원 AI 때 구현].
- 서 있거나 상호작용 중에도 보물 소리는 난다 [제안, 이전과 같음].
- 개발용: 바닥에 소리 반경 원 표시(유지), 1번만 나는 소리(공격)는 잠깐 깜빡이는 원.
- 공격 적중 = 경비원을 맞힘(경직 면역이어도 적중), 의적만 맞히거나 아무도 못 맞히면 빗나감 [제안, 확인 필요]
