## 1. 한 줄 요약
- 클라와 서버의 `protocol.h` 는 **내용이 똑같다(v2.1)**. 서버 팀원이 겪은 "프로토콜 버전 불일치"는 **v2.1 이전에 빌드된 옛 클라 DLL**(로그상 클라가 `0x00010000` = v1.0 을 보냄) 때문이다 → 아래 2장대로 **클라를 다시 빌드**하면 된다.
- **서버 맵 파일이 아직 옛 배치(v1)** 다. 이대로는 금고·숨는 곳·창고·탈출구 위치가 클라 레벨과 달라 게임이 안 된다 → 3장대로 **맵 파일 하나만 교체**.
- 오늘 밤 서버 최신본(코드 수정 없음 + 맵 파일만 v2)으로 **로그인 → 방 → 게임 → 금고 → 반납 → 탈출구 열림 → 탈출 → 결과 → 로비** 전 과정을 실서버로 확인했다(4장).

## 6. 알려진 문제 / 주의
1. **완료 직전 손 뗌**: 클라는 남은 시간 0.15초 이하에서 손을 떼면 취소를 미루고 0.6초 안에 서버 완료가 없을 때만 취소한다(실서버 확인 완료).
2. **창고 구출 판단**: 다른 플레이어 감금은 서버 상태(ES_JAILED)로 판단하도록 고침. 단 창고 문 위 안내 문구는 아직 로컬 기준이라 "갇힌 의적이 없습니다"로 보일 수 있음(눌러도 구출됨).
3. 숨은 상태에서 바로 다른 상호작용을 누르면 먼저 "나오기"만 된다 → 한 번 더 누를 것.
4. 줍자마자 0.3초 안에 다른 길게 누르기를 시작하면 방금 주운 보물 이름이 다른 보물로 보일 수 있음(가치·무게는 서버 값으로 맞춰짐).
5. **문 없는 방(Room_20 = 서버 L2)에 경비원 1명이 갇혀 있다.** 그 방에 들어가면 그 경비원에게 잡히는데, 경비원이 방을 못 나가 창고로 데려가지도 못한다 → 그 의적은 판이 끝날 때까지 묶임. 서버가 경비원 시작 위치를 옮기거나 모델러가 문을 내야 함.
6. 경비원이 강하다: 혼자 금고(30초)를 열다 25~40초 만에 잡히는 판이 많았다(시야 15m·45° 임시값).
7. 보물 이름: 서버 보물 표가 아직 임시값이라 **이름은 클라 표(`type_id−1`), 가치·무게는 서버 값**으로 보인다. 서버가 `treasure_types.json` 을 반영하면 이름도 일치.
8. 상호작용 거리: 서버는 대상의 `interact_pos`(앞면)에서 150cm. 금고 옆·뒤에서 누르면 거절될 수 있다 → 앞에서.
9. v2.1에 없는 기능(맵·난이도 선택, 전적, 결과 후 대기실)은 화면에서 숨김.
10. 이름표는 영문(엔진 기본 글꼴에 한글 없음).
11. 에디터 창이 뒤에 있으면 PIE가 초당 3프레임으로 느려져 CS_MOVE 가 적게 나간다(5초 16번). 시험 때는 에디터 창을 앞에 둘 것.
12. 실서버 모드에서 로컬 판정용 개발 명령(VHAddValue, VHOpenExit, VHCapture 등)은 쓰지 말 것. 실서버용: `VHUse 이름 초`, `VHGoto 이름`(이제 `Floor_Exit`·`Room_20` 같은 일반 액터도 됨), `VHAttack [거리]`(가장 가까운 경비원 공격).
