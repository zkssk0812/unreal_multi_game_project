# 혼자 플레이하기 — 우리 PC에서 실서버 켜고 접속 (초보자용)

최종 갱신 2026-10-28. 서버 = 정호님 수정본(`C:\UnrealProjects\VaultHeistServerLatest`), 클라 = 이 프로젝트(`client/menu-ui`).

준비물은 바탕화면의 두 파일뿐입니다.
- **`VaultHeist_서버켜기.bat`** — 서버 켜기
- **`VaultHeist_봇붙이기.bat`** — 자동으로 움직이는 다른 플레이어(봇) 붙이기
- (원본은 프로젝트 `Tools/LocalTest/` 에도 있습니다. 바탕화면 파일을 지웠으면 거기서 다시 복사하세요.)

---

## 1. 서버 켜기 (한 번만)
1. 바탕화면 **`VaultHeist_서버켜기.bat`** 를 더블클릭합니다.
2. 검은 창이 뜨고 맨 아래쪽에 다음 줄이 보이면 준비 완료입니다.
   ```
   Listener: 포트 9000, AcceptEx 16개 대기
   ```
   - 바로 위의 `[Map] mansion_1f v2: 금고 후보 10, 숨는 곳 4 …` 는 맵이 제대로 읽혔다는 뜻입니다.
   - 노란 `[WARN]` 4줄(경비원 스폰 1, 순찰 지점 35·39·41)은 지금 맵에서 늘 나오는 경고입니다. 무시해도 됩니다(6장 참고).
3. **이 창은 게임하는 동안 계속 열어 두세요.** 창 안에서 아무것도 안 쓰고 `Enter` 만 누르면 서버가 꺼집니다.
4. "Windows 보안 경고(방화벽)" 창이 뜨면 **[허용]** 을 누르세요. (같은 PC에서만 할 거면 [취소]해도 됩니다.)
5. "서버가 이미 켜져 있습니다" 라고 나오면, 작업 표시줄에서 기존 서버 창(`VaultHeist 테스트 서버`)을 찾아 그대로 쓰면 됩니다.

**서버 끄기**: 서버 창 오른쪽 위 **X**, 또는 창에 `quit` 입력 후 `Enter`.

## 2. 에디터에서 접속하기
1. **에픽게임즈 런처 → 라이브러리 → 내 프로젝트 → MCPTest** 를 열어 에디터를 켭니다.
2. 위쪽 레벨 탭이 **`L_MainMenu`** 인지 봅니다. 아니면 아래 **콘텐츠 드로어 → 콘텐츠 → VaultHeist → Maps → `L_MainMenu`** 를 더블클릭합니다. ("저장하시겠습니까?" 가 뜨면 일부러 고친 게 없으면 **저장 안 함**)
3. 툴바의 초록색 **▶ (플레이)** 를 누릅니다. (단축키 `Alt + P`)
4. 메인화면 맨 아래 **주소칸**이 `127.0.0.1:9000` 인지 확인하고 **[실서버로 전환]** 을 누릅니다. (주소칸을 클릭하고 `Enter` 를 눌러도 됩니다)
   - 그 위 글자가 **`접속 대상: 실서버 TCP 127.0.0.1:9000`** 으로 바뀌면 성공입니다.
   - ▶ 플레이를 새로 누를 때마다 기본값(가짜 서버)으로 돌아오므로, **플레이할 때마다 한 번씩** 눌러 주세요.
5. **[시작하기]** → 이름을 **영문 2~12자**로 입력(예: `Yoongi`) → **[확인]**.
   - 봇 이름 `Carl`, `Dave` 는 쓰지 마세요(이미 접속 중인 이름이라고 나옵니다).
6. 로비에서 **[방 만들기] → [만들기]** (또는 **[빠른 찾기]**: 빈자리 있는 방에 들어가고, 없으면 방을 만들어 줍니다).
7. 대기실에서 **캐릭터 1개 + 퍽 3개**를 고르고 **[준비]**. 혼자면 바로 게임이 시작됩니다.

> 에디터 창이 다른 창 뒤에 있으면 게임이 아주 느려집니다. 플레이하는 동안은 에디터 창을 앞에 두세요.

## 3. 게임 한 판 하는 법
| 키 | 동작 |
|---|---|
| 마우스 커서 | 바라보는 방향(손전등 방향) |
| `W` `A` `S` `D` | 이동 (커서 쪽이 앞) |
| 왼쪽 `Shift` 누른 채 이동 | 달리기 (스테미나 소모, 경비원이 소리를 들음) |
| `Space` | 구르기 |
| 마우스 **좌클릭** | 공격 (경비원을 잠깐 경직시킴) |
| 마우스 **우클릭** 또는 `G` | 상호작용 (금고 열기는 **누르고 있기**) |
| `R` | 손전등 켜기/끄기 |
| `Esc` | 플레이 종료 |

순서
1. **금고 앞**(정면)에서 우클릭/`G` 를 **30초 동안 누르고** 있으면 금고가 열립니다. 손을 떼면 처음부터.
2. 열린 금고에서 우클릭/`G` 를 **한 번** 누르면 보물을 줍습니다. (한 사람 최대 20kg)
3. 바닥의 **초록 반납지점 가운데**에 서서 우클릭/`G` 한 번 → 반납. 오른쪽 위 `반납 가치 ○○ / 10,000$` 가 올라갑니다. 반납지점은 1분마다 자리가 바뀝니다.
4. 팀 반납이 **10,000$ 를 넘으면** "탈출구가 열렸습니다" 알림 → **탈출구(옆문) 밖**으로 나가면 탈출 성공.
5. 결과창(승리/패배, 점수) → **[로비로]** 또는 15초 뒤 자동으로 로비.

팁
- 경비원에게 잡히면 창고에 갇힙니다. 혼자면 잡히는 순간 판이 끝납니다(다시 하기가 빠름).
- **숨는 곳**(옷장 등)에서 우클릭/`G` 를 1초 누르면 숨습니다. 숨은 걸 경비원에게 들키면 끌려 나옵니다.
- 경비원을 **좌클릭으로 때리면** 몇 초 경직됩니다. 그동안 도망가세요.
- ⚠️ **문 없는 방(Room_20)** 안에 경비원 한 명이 갇혀 있습니다. 그 경비원에게 잡히면 판이 끝날 때까지 움직일 수 없습니다(6장).

## 4. 봇 붙이기 (2명·3명 판 연습)
봇 = 같은 게임을 자동으로 하는 작은 창. 로그인 → 빠른 찾기 → 캐릭터·퍽 선택 → 인원이 모이면 준비 → 게임 중에는 이리저리 걸어 다닙니다. **금고를 열거나 공격하지는 않습니다.** 금방 잡히므로 "창고 구출" 연습 상대로 좋습니다.

1. 위 2장대로 접속해서 **방을 먼저 만들고 대기실 화면**에서 기다립니다. (캐릭터·퍽은 미리 골라도 되지만 [준비]는 아직 누르지 마세요)
2. 바탕화면 **`VaultHeist_봇붙이기.bat`** 더블클릭 → 숫자 입력 후 `Enter`
   - `1` = 봇 1개(Carl) → 나와 2명 판
   - `2` = 봇 2개(Carl, Dave) → 나와 3명 판
3. 20~40초 뒤 작은 게임 창이 뜨고, 대기실에 봇이 들어와 캐릭터·퍽을 고르고 **준비**합니다.
4. 내가 **[준비]** 를 누르면 게임 시작.
5. 판이 끝나면 봇은 로비로 돌아가 다시 빠른 찾기를 합니다. 다음 판에 또 쓰려면 내가 다시 방을 만들면 봇이 들어옵니다.
6. **봇 끄기**: 봇 창의 **X**.

- 봇 창 하나가 메모리를 약 1GB 씁니다. 느리면 봇을 1개만 쓰세요.
- 봇이 먼저 떠서 자기 방을 만들었으면, 나는 로비에서 **[빠른 찾기]** 로 그 방에 들어가면 됩니다.

### 창고 구출 해 보기
봇이 잡혀 경비원에게 창고(Jail)로 옮겨져 갇히면 → 창고 문 앞에서 우클릭/`G` 를 **5초** 누르고 있으면 구출됩니다. 문 위 안내 글자가 "갇힌 의적이 없습니다"로 보여도 눌러 보세요(알려진 문제, 구출은 됩니다).

## 5. 문제가 생기면
| 증상 | 해결 |
|---|---|
| 로그인 화면 "서버에 연결할 수 없습니다" | 서버 창이 켜져 있는지 확인(1장). 메인화면이 `실서버 TCP 127.0.0.1:9000` 인지 확인 |
| "이미 접속 중인 이름입니다" | 다른 이름 사용. 봇 이름(Carl, Dave)과 겹쳐도 이렇게 나옵니다 |
| "게임 버전이 서버와 다릅니다" | 클라가 옛 빌드. 에디터를 끄고 프로젝트 `Binaries` 폴더를 지운 뒤 다시 열어 [예](다시 빌드) |
| 서버 창이 켜지자마자 꺼짐 | 이미 다른 서버가 9000번을 쓰는 중. 작업 관리자에서 `GameServer.exe` 를 끝내고 다시 실행 |
| 게임이 아주 느림 | 에디터 창을 앞으로. 봇 수를 줄이기 |
| 서버 실행 파일이 없다고 나옴 | 아래 "서버 다시 빌드" |

## 6. 알려진 문제 (2026-10-28 기준)
1. **문 없는 방의 경비원**: 서버 시작 경고 `경비원 스폰 1이 의적 쪽과 이어지지 않음` 이 그 경비원입니다. 그 경비원에게 잡히면 창고로 옮겨지지 않고 판이 끝날 때까지 묶입니다. 맵 데이터(경비원 시작 위치)를 고쳐야 합니다 → 정호님과 상의 중.
2. 경비원이 강합니다. 혼자 금고(30초)를 여는 동안 잡히는 판이 자주 나옵니다.
3. 창고 문 위 안내 문구가 "갇힌 의적이 없습니다"로 보일 수 있음(눌러서 구출은 됨).
4. 숨은 채로 다른 상호작용을 누르면 먼저 숨은 곳에서 나오기만 됩니다. 한 번 더 누르세요.
5. 결과창의 "대기실로", 맵·난이도 선택, 전적은 서버(v2.1)에 없어서 숨겨져 있습니다.
