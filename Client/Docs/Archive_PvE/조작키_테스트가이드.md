# 조작키·테스트 가이드 (L_Mansion_1F · L_InteractionTest)

> 2026-10-26 갱신: 게임 레벨이 **저택 1층 블록아웃 `L_Mansion_1F`** 로 바뀌었다(1-4장). `L_InteractionTest` 는 기능 테스트용으로 남겨 두었다.
> 2026-10-26 ⟪기획 변경⟫: **이동 기준이 마우스 커서 방향**으로 바뀌었다 — 몸 전체가 커서를 바라보고 W·A·S·D는 커서 기준 앞·왼쪽·뒤·오른쪽(2장).
> 2026-10-25 기준(11단계 커밋 `0a38f9c`). 실제 설정·코드를 확인해서 썼다.
> - 입력: `Content/VaultHeist/Input/IMC_VHGameplay` (상호작용·달리기·손전등·구르기·공격), 이동은 템플릿 `IMC_Default`
> - 코드: `AVHGamePlayerController`(입력 연결·콘솔 명령), 캐릭터 컴포넌트 `Aim`(시선)·`Action`(달리기·구르기·공격·스테미나)·`StatusEffect`(경직·면역)·`Interaction`·`TreasureCarrier`, 게임 규칙 `UVHMatchSubsystem`
> - 수치: `DA_VHGameplayConfig`(캐릭터·공격·보물·반납지점·제한 시간), `DA_VHInteractionConfig`(상호작용 시간·소리·손전등)
>
> 10-23 버전에서 바뀐 점: 탑뷰 카메라, Space = 구르기(점프 없음), 좌클릭 공격, 스테미나, 무게(kg)·가치($) 보물, 금고에서만 보물, 반납지점, 탈출구 자동 열림·자동 탈출, 빛 안에서만 상호작용 + 테두리, 5분 제한 시간, 메뉴 → 게임 → 결과창 한 흐름.

## 1. 테스트 시작 방법

### 1-1. 두 가지 방법
| 방법 | 순서 | 끝나면 |
|---|---|---|
| **A. 메뉴부터 (전체 흐름)** | 에디터가 처음 여는 `L_MainMenu` 에서 **▶ 플레이** → [시작하기] → 이름 입력 [확인] → 로비 [빠른 찾기] 또는 [방 만들기] → 대기실에서 캐릭터 1개 + 퍽 3개 고르고 [준비] → 가짜 플레이어 2명이 준비하면 게임 레벨 **L_Mansion_1F(저택)** 로 이동 | 탈출하거나 5분이 지나면 결과창 → [대기실로] / [로비로] |
| **B. 저택 레벨만** | 콘텐츠 드로어 `콘텐츠 → VaultHeist → Maps → Mansion → L_Mansion_1F` 더블클릭 → **▶ 플레이** | 결과창에 "(테스트 플레이)" 표시 → 버튼을 누르면 메인화면 |
| **C. 기능 테스트 레벨** | `콘텐츠 → VaultHeist → Maps → L_InteractionTest` 더블클릭 → **▶ 플레이** (방 6개짜리 작은 레벨, 아래 1-3장) | B와 같음 |

- 메뉴에서 들어갈 게임 레벨은 `Config/DefaultGame.ini` 의 `GameLevel=` 줄로 정한다(맵 교체 방법: `Docs/맵_교체_가이드.md`).

- 서버는 기본으로 **Mock 서버(가짜 서버)** 를 쓴다. 메인화면 아래 `접속 대상: Mock 서버(가짜 서버)` 로 확인.
- 레벨을 바꿀 때 "변경 사항을 저장하시겠습니까?" 창이 뜨면, 일부러 고친 게 없다면 **저장 안 함**.

### 1-2. 플레이 시작 / 종료
| 하고 싶은 것 | 방법 |
|---|---|
| 플레이 시작 | 툴바 **▶ (플레이)**, 또는 `Alt + P` |
| 마우스를 에디터로 빼기 | `Shift + F1` |
| 다시 게임 조작 | 게임 화면(뷰포트)을 한 번 클릭 (좌클릭은 공격이므로 **가운데 버튼**이나 빈 곳 클릭 권장) |
| 플레이 종료 | `Esc`, 또는 툴바 **■ (중지)** |

- 게임 레벨에서는 **마우스 커서가 항상 보인다**(탑뷰라서 커서 쪽을 바라본다).
- 에디터 창이 뒤로 가 있으면 게임이 아주 느려진다. 게임 화면을 클릭해서 앞으로 가져온다.

### 1-3. 기능 테스트 레벨(L_InteractionTest) 배치 (화면 기준: 위 = 북쪽)
방 6개(3×2), 방 하나는 약 13m × 15m. 방 사이 벽에는 3m 폭 문이 있다. 시작 위치는 **현관**.

```
                         ┌탈출구(ExitGate)┐ ← 금고실 위쪽 벽 바깥
 ┌──────────────────────┬──────────────────────┐
 │ 침실 Bedroom          │ 금고실 Vault          │
 │ 창고(Jail)·Safe_6     │ Safe_7·Safe_8         │
 │ 경비원 Guard_2         │ 옷장 HideSpot_3       │
 ├──────────────────────┼──────────────────────┤
 │ 서재 Study            │ 식당 Dining           │
 │ Safe_3·Safe_4         │ Safe_5·경비원 Guard_1 │
 ├──────────────────────┼──────────────────────┤
 │ 현관 Entrance  ★시작   │ 응접실 Parlor          │
 │ Safe_1·HideSpot_1     │ Safe_2·HideSpot_2     │
 └──────────────────────┴──────────────────────┘
          (왼쪽)                    (오른쪽)
```

| 오브젝트 | 레벨 이름(라벨) | 있는 곳 |
|---|---|---|
| 금고 후보 8개 | Safe_1 ~ Safe_8 | 위 그림. 대부분 방의 바깥쪽 벽에 붙어 있다. **매 판 5개만 등장**(2026-10-26부터, 나머지는 숨겨짐) |
| 숨는 곳(옷장) 3개 | HideSpot_1~3 | 현관·응접실 아래쪽 벽, 금고실 오른쪽 벽 |
| 창고(감옥) | Jail | 침실 왼쪽 벽 |
| 탈출구 | ExitGate | 금고실 위쪽 벽. 열리면 문 너머 바깥 통로로 들어가면 자동 탈출 |
| 더미 경비원 2명 | Guard_1, Guard_2 | 식당, 침실 (움직이지 않음, 공격 테스트용) |
| 반납지점 5곳 | (게임 시작 때 생성) | 방마다 무작위 위치. **빛과 상관없이 항상 보임** |

> 걸어가기 귀찮으면 콘솔 `VHGoto 이름` 으로 그 오브젝트 앞으로 순간이동 (예: `VHGoto Safe_8`, `VHGoto ExitGate`, `VHGoto ReturnPoint`). 4장 참고.

### 1-4. 저택 1층 맵 (L_Mansion_1F) — 기본 게임 레벨
모델러의 블록아웃 맵(약 98m × 69m, 벽 높이 3m, 천장 없음). 그림: `Docs/Mansion_1F_배치안.png`(배치), `Docs/Mansion_1F_지역.png`(방 번호).
화면 위쪽 = 평면도 위쪽(현관 돌출부가 위). 맵이 커서 **콘솔 `VHGoto` 로 이동하며 테스트하는 것을 권장**한다.

| 오브젝트 | 레벨 이름(라벨) | 있는 곳 (방 번호는 지역 그림) |
|---|---|---|
| 시작 지점 | PlayerStart | **큰 홀(15번) 가운데** = 기획의 "비어 있는 거대한 금고 안" |
| 금고 후보 10개 | Safe_01 ~ Safe_10 | 방 1·4·7·12·17·19·25·28·30·33. **매 판 5개만 등장**, 어느 것이 나왔는지는 출력 로그 `[Treasure] Safe_xx ← 보물` 로 확인 |
| 탈출구 | ExitGate | **서쪽(왼쪽) 옆문**(방 9 옆). 문 바깥 바닥판(Floor_Exit)에 들어가면 탈출 |
| 창고(감옥) | Jail | 아래쪽 줄 방 31의 아래쪽 벽 |
| 숨는 곳 4개 | HideSpot_1~4 | 방 10, 14, 24, 21 |
| 더미 경비원 | Guard_1 | 위쪽 복도 가운데 (움직이지 않음) |
| 정문 막는 벽 | InvisibleWall_FrontDoor | 현관 정문 구멍. 게임 중 안 보이지만 지나갈 수 없다(바깥에 바닥이 없어서) |
| 반납지점 5곳 | (게임 중 생성) | 방 30곳 중 무작위(복도·문 없는 방 11·13·20 제외) |

- **벽 가림 처리**: 카메라 쪽(화면 아래쪽) 벽 뒤에 서도 벽에 둥근 구멍이 뚫려 캐릭터가 보인다(`S` 로 아래쪽 벽에 붙어 확인).
- 미니맵이 없으므로 HUD의 `위치: 방 N (a, b)` 로 지금 방 번호를 확인한다(복도는 `방 밖`).
- 이 맵에서 바로 하는 빠른 확인:
```
VHFastInteract 0.1
VHGoto Safe_03        (로그에 등장한 금고 번호로)
VHGoto ReturnPoint    (보물을 든 뒤 반납)
VHGoto Jail
VHAddValue 10000
VHGoto ExitGate       → 커서를 탈출구(화면 왼쪽)에 두고 W로 걸어 들어가면 탈출
```
- `VHGoto` 뒤에는 **마우스 커서를 오브젝트 쪽에** 둬야 그 오브젝트를 바라본다(탑뷰라 시선 = 커서 방향).

## 2. 기본 조작키

| 키 | 동작 | 비고 |
|---|---|---|
| `W` `A` `S` `D` | 이동 | ⟪기획 변경 2026-10-26⟫ **커서 방향 기준**: W = 커서 쪽(앞), S = 커서 반대쪽(뒤), A = 바라보는 방향의 왼쪽, D = 오른쪽. 대각선도 같은 기준. 걷기 **3m/s**, 뒤·옆도 같은 속도 |
| 마우스 커서 | 바라보는 방향(손전등 방향) | ⟪기획 변경⟫ **몸 전체가 커서가 가리키는 바닥 지점을 계속 바라본다**(각도 제한 없음, 움직이는 동안에도). 커서가 캐릭터 1m 안이면 마지막 방향 유지. 머리 위 작은 원뿔이 시선 표시 |
| `Shift`(왼쪽) 누른 채 이동 | 달리기 | **6m/s**, 스테미나 **초당 10** 소모. 탈진이면 안 됨 |
| `Space` | 구르기 | 0.5초 동안 9m/s로 약 4.5m, 스테미나 **20**. **누르고 있는 이동 키 방향(커서 기준)**, 이동 키가 없으면 **커서 쪽**으로. 구르는 동안 **무적**(경직 안 됨), 몸은 계속 커서를 바라봄. 무게 감속 없음 |
| **마우스 좌클릭** | 공격 | 1초 동작, 스테미나 **30**. 앞쪽 **1.5m · 120° 부채꼴**. 공격 중에도 이동 가능 |
| **마우스 우클릭** 또는 **`G`** | 상호작용 | 대상에 따라 **짧게**(한 번 누르면 끝까지) / **길게**(누르고 있어야 진행) |
| `R` | 손전등 켜기/끄기 | 0.3초 안 연타는 무시. 숨음·잡힘·갇힘 중에는 켤 수 없음 |
| `~` (숫자 1 왼쪽) | 개발용 콘솔 | 4장 |
| `Shift + F1` | 마우스를 에디터로 빼기 | |
| `Esc` | 플레이 종료 | |

### 2-1. 스테미나
- 최대 **100**, 초당 **10** 회복(달리기·구르기·공격 중이 아닐 때).
- **0이 되면 탈진**: 화면 알림 `탈진! 스테미나가 다 찰 때까지 달리기·구르기·공격을 할 수 없습니다`. 회복 속도가 **절반**(초당 5)이 되고, **100까지 다 차야** 풀린다(약 20초).
- 스테미나가 조금이라도 남아 있으면 구르기·공격은 된다(모자라도 0까지 쓰고 탈진).

### 2-2. 무게 (임시 규칙 — 기획 확정 전)
- 1인 최대 **10개 · 20kg**. 줍고 나서 20kg을 **넘게 되면 줍지 못한다**(`너무 무거워 더 들 수 없습니다 (18 + 4 > 20kg)`).
- 무게에 **비례해서** 느려진다: 0kg = 감속 0%, 20kg = **최대 속도 50% 감소**(걷기 1.5m/s, 달리기 3m/s).
- 달리기·구르기·공격의 스테미나 소비도 비례해서 **1배 → 2배**.
- **구르기 속도는 감속 없음.**

### 2-3. 길게 누르기 중에는
- 제자리에 멈춘다. **이동 키 / Space / 좌클릭 / 키 떼기 / 경직**이면 즉시 취소. (Space·좌클릭은 구르기·공격 대신 **취소만** 한다)
- 길게 누르기를 **시작한 뒤에는 빛이 대상에서 벗어나도 취소되지 않는다.**

### 2-4. 경직 (공격을 맞으면)
- **3초** 동안 움직이지 못하고, 머리 위에 노란 별이 돈다. **들고 있던 보물을 전부 주변 바닥에 떨어뜨린다**(떨어진 보물은 다시 주울 수 있고 가치·무게 그대로).
- 경직이 풀린 뒤 **10초 면역**(다시 경직되지 않음). 구르는 중(무적)에도 경직되지 않는다.
- 지금은 경비원 AI가 없어서, 의적이 경직되는 상황은 `VHStunSelf` 로 만든다.

## 3. 기능별 테스트 방법

> **빛 안에서만 상호작용한다.** 손전등(R)이 비추는 범위 안에 있는 오브젝트만 테두리가 생기고 대상이 된다.
> - 테두리 색: **옅은 노랑** = 빛 안(상호작용 후보), **주황** = 지금 고른 대상, **회색** = 고른 대상이지만 지금은 못 함
> - 예외: **반납지점**은 항상 보이고 빛과 상관없이 사용. **숨은 상태의 "나오기"** 는 손전등 없이 가능
> - 대상은 1.5m 안 + 바라보는 방향(마우스 쪽) 좌우 75° 안에서 가장 가까운 것 하나

### 3-1. 금고 열기 (길게 30초) → 보물 꺼내기 (짧게 0.5초)
1. **R** 로 손전등을 켜고 현관의 **Safe_1** 로 간다(또는 `VHGoto Safe_1`). 금고를 비추면 테두리가 생긴다.
2. 마우스로 금고를 바라보면 `[우클릭/G] 길게 눌러 금고 열기 (30초)`.
3. **우클릭(또는 G)을 누르고 있는다.** 떼면 멈추고 진행도는 남는다.
4. 다 열리면 알림 `금고가 열렸습니다! 보물을 챙기세요`, 안내가 `보물 꺼내기 (루비 반지 · 1800$ · 1kg)` 처럼 **보물 이름·가치·무게**를 보여준다.
5. **짧게 누르면** 보물이 내 것이 된다. 왼쪽 위 `보물 1/10  무게 1.0/20kg  가치 1800$`.
- 금고 후보 중 **매 판 5개만 등장**하고, 등장한 금고마다 보물 **1개**(10종 중에서, 판마다 섞임).
- 보물 표는 **아무 5개를 뽑아도 합계가 11,000$ 이상**이라 등장한 금고 5개를 다 열면 항상 목표 10,000$를 채울 수 있다(2026-10-26 변경).
- 30초가 길면 `VHFastInteract 0.1`(3초) 또는 `VHSafeProgress 0.9`.

|---|---|---|

**일부러 실패시켜 보기**
- 손전등을 끄고 금고 앞에 서기 → 테두리·안내가 없다(빛 밖)
- 누르는 도중 W·Space·좌클릭 → 즉시 취소, 진행도 유지
- 무거운 보물: `VHSetTreasure 9` 로 거의 꽉 채운 뒤 금고 보물 줍기 → 회색 `너무 무거워 더 들 수 없습니다`
- 다른 의적 사용 중: `VHDummyUse Safe_1` → 회색 `다른 의적이 사용 중입니다`

### 3-2. 반납지점 (짧게 0.5초)
- 게임 시작 때 **5곳**이 방마다 무작위로 생긴다. 바닥의 **초록 사각형**, 위에 남은 시간 글자가 보인다. 어두워도 항상 보인다.
- 생긴 지 **50초**가 지나면 **빨간색**, **60초**에 사라지고 다른 곳에 새로 생긴다. 한 번 쓰면 사라지고 다른 곳에 새로 생긴다.
1. 보물을 든 채 반납지점 위/앞에서 `[우클릭/G] 보물 반납 (2개 · 3300$)` → **짧게 누른다.**
2. 들고 있던 보물이 전부 반납되고, 오른쪽 위 `반납 가치 3,300 / 10,000$` 가 오른다.
- 보물이 없으면 회색 `반납할 보물이 없습니다`.
- 빨리 확인: `VHReturnAge 49` (1초 뒤 빨강), `VHReturnAge 59` (1초 뒤 사라짐·새로 생김).

### 3-3. 탈출구 (자동으로 열리고, 걸어 들어가면 자동 탈출)
1. 반납 가치가 **10,000$** 이상이 되면 화면 가운데 `탈출구가 열렸습니다! 탈출구 안으로 들어가 탈출하세요`, 탈출구 문이 열린다.
2. 금고실 위쪽 벽의 탈출구로 **걸어 들어가면** 자동으로 탈출. 상호작용 키는 필요 없다.
3. 3초 뒤 결과창으로 넘어간다.
- 잠겨 있을 때는 문이 막혀 있다. 왼쪽 위 `탈출구: 잠김 (반납 가치 10,000$ 필요)`.
- 빨리 확인: `VHAddValue 10000` 또는 `VHOpenExit` → `VHGoto ExitGate` → 커서를 탈출구 쪽에 두고 **W** 로 걸어 들어가기(W = 커서 쪽).
- 반납하지 않고 들고 탈출한 보물은 가치에 들어가지 않는다(가정).

### 3-4. 제한 시간 (5분)
- 오른쪽 위 `남은 시간 4:53`. 30초 이하이면 빨간색.
- 0이 되면 `시간 초과! 탈출하지 못했습니다` → 결과창(패배).
- 빨리 확인: `VHSetTime 10` (10초 남김), `VHSetTime 1`.

### 3-5. 공격 · 경비원 경직
1. 식당의 **Guard_1** 앞으로 간다(`VHGoto` 는 상호작용 오브젝트만 되므로 걸어가거나 `VHSpawnGuard` 로 내 앞에 만든다).
2. 경비원을 바라보고 **좌클릭**. 0.2초 뒤 0.5초 동안 앞쪽 부채꼴(1.5m, 120°)이 판정된다(빨간 부채꼴 표시).
3. 맞으면 경비원이 **3초 경직**(기울어지고 노란 별) + 알림. 그 뒤 **10초 면역**.
4. 경비원이 보물을 들고 있었다면 주변 바닥에 떨어진다 → 빛을 비추고 **짧게** 주워 되찾기.
- 경비원에게 보물 쥐여주기: `VHGuardGive 2`
- 소리: 빗나감 5m, 맞음 20m (경비원이 들을 수 있는 범위)
- 다른 의적을 때리면 아무 일도 없다(아군 공격 없음).

### 3-6. 잡힘 (경비원 AI 대신)
- `VHCapture` → 내가 가장 가까운 경비원에게 잡힘. 들고 있던 보물이 **그 경비원에게 넘어간다**. `VHRelease` 로 풀림.
- 경비원을 때려 경직시키면 그 보물을 바닥에 떨어뜨린다 → 다시 줍기.

### 3-7. 경직되어 보물 떨어뜨리기
- 보물을 든 채 `VHStunSelf` → 3초 경직, 보물이 내 주변 바닥에 흩어진다. 경직이 풀린 뒤 빛을 비추고 줍는다(이름·가치·무게 그대로).
- 바닥 보물은 **경직될 때만** 생긴다(게임 시작 때 바닥 보물 없음).

### 3-8. 숨는 곳 (짧게 — 들어가기 1초 / 나오기 0.5초)
1. 손전등으로 옷장을 비추고 `[우클릭/G] 숨기` → 짧게 누른다.
2. 1초 뒤 캐릭터가 사라지고 `상태: 숨음`, 소리 0m. (카메라는 그대로 탑뷰)
3. 숨은 동안은 손전등을 켤 수 없지만 **"나오기"는 빛 없이** 짧게 누르면 된다.

### 3-9. 창고 문 — 구출 (길게 5초, 떼면 처음부터)
- `VHJailDummy` → 더미 의적이 창고에 갇힘 → 침실 왼쪽 벽 창고 문을 비추고 **5초** 누르고 있기 → `의적 1명을 구출했습니다!`
- 갇힌 사람이 없으면 회색 `창고에 갇힌 의적이 없습니다`.

## 4. 개발용 콘솔 명령

### 4-1. 콘솔 여는 법
- 플레이 중 **`~` 키** → 아래 입력줄에 명령 → `Enter`. 또는 `Shift + F1` 로 마우스를 빼서 에디터 맨 아래 **Cmd** 입력칸에 쳐도 된다.
- 대소문자 구분 없음. 결과는 화면 왼쪽 위 하늘색 글자. `VHHelp` 로 목록 표시.

### 4-2. 전체 목록 (게임 레벨, `AVHGamePlayerController`)
| 명령 | 예시 | 하는 일 |
|---|---|---|
| `VHHelp` | `VHHelp` | 명령 목록 표시 |
| `VHSetTreasure 개수` | `VHSetTreasure 3` | 내 보물 개수를 0~10으로 (금고 보물 표에서 차례로, 개발용이라 무게 한도 무시) |
| `VHStunSelf` | `VHStunSelf` | 내가 3초 경직 → 보물을 바닥에 떨어뜨림 |
| `VHStamina 값` | `VHStamina 0` | 스테미나를 값으로 (0 = 탈진) |
| `VHFastInteract [배율]` | `VHFastInteract 0.1` | 상호작용 시간 배율 (0.1 = 10배 빠르게, 1 = 원래) |
| `VHSafeProgress [0~1]` | `VHSafeProgress 0.9` | 가장 가까운 닫힌 금고의 진행도 |
| `VHResetSafes` | `VHResetSafes` | 사용 중이 아닌 금고를 처음 상태로 |
| `VHCapture` / `VHRelease` | `VHCapture` | 가장 가까운 경비원에게 잡힘(보물이 경비원에게) / 풀려남 |
| `VHGuardGive [개수]` | `VHGuardGive 2` | 가장 가까운 경비원에게 보물 쥐여주기 |
| `VHSpawnGuard` | `VHSpawnGuard` | 내 시선 방향 2m 앞에 더미 경비원 생성 |
| `VHAddValue 금액` | `VHAddValue 10000` | 반납 가치 더하기 (10,000$ 이상이면 탈출구 열림) |
| `VHOpenExit` | `VHOpenExit` | 탈출구 바로 열기 |
| `VHSetTime 초` | `VHSetTime 10` | 남은 제한 시간 설정 (0 → 시간 초과) |
| `VHReturnAge 초` | `VHReturnAge 49` | 지금 있는 반납지점들의 나이 설정 (50초 빨강, 60초 사라짐) |
| `VHShowNoise 1\|0` | `VHShowNoise 0` | 소리 반경 원 표시 켜기/끄기 |
| `VHHoldInteract [초]` / `VHInteractUp` | `VHHoldInteract 0` | 상호작용 키를 누르고 있는 것처럼 / 뗀 것처럼 |
| `VHGoto 이름` | `VHGoto Safe_8` | 이름에 그 글자가 들어간 상호작용 오브젝트 앞으로 순간이동. 저택: `Safe_01~10`(이번 판에 등장한 금고만), `HideSpot_1~4`, `Jail`, `ExitGate`, `ReturnPoint`(첫 번째 반납지점) · 기능 테스트 레벨: `Safe_1~8`, `HideSpot_1~3` |
| `VHFlashlight` | `VHFlashlight` | 손전등 켜기/끄기 (R과 같음) |
| `VHSpawnDummy [1~2]` | `VHSpawnDummy` | 더미 의적 생성 |
| `VHDummyUse 이름 [초]` | `VHDummyUse Safe_1 5` | 더미 의적이 그 오브젝트 사용 (동시 1명 제한 확인) |
| `VHJailDummy` / `VHJailSelf` / `VHReleaseAll` | | 더미·나를 창고에 가둠 / 전원 풀기 |

> 없어진 명령: `VHDropTreasure` (바닥 보물은 경직될 때만 생기므로 → `VHStunSelf` 사용)

### 5-3. 그 밖
