## 시연 성능 시나리오

| 순서 | 장면 | 보여 주는 것 |
|---|---|---|
| 1 | 실제 플레이 | 팀원 3명이 클라로 한 판 진행 |
| 2 | 봇 투입 | 다른 PC에서 `DummyClient bot 1000` 실행 → 봇 1,000명이 방 단위로 게임 진행 |
| 3 | 실시간 지표 | 서버 화면: 동시 접속, 방 수, 틱 처리 시간(평균·최대), 초당 패킷, 송신 KB/s, CPU % |
| 4 | 체감 확인 | 봇이 몰려도 1번의 실제 플레이가 끊기지 않음 (틱 처리 시간 < 50ms) |
| 5 | 최적화 결과 | 미리 잰 성능 향상 비율 표(패킷 수·KB/s·CPU·틱 시간)를 보여 줌 |

- 예상치(설계 계산): 이 PC(논리 코어 24개)에서 CPU 90%일 때 3,000~6,000명. 그 근처에서는 CPU보다 초당 패킷 수가 먼저 한계 → A-②의 "보낼 것 묶기"가 가장 중요
- 성능 코드(ServerCore)는 건드리지 않고, 그 위에 측정·봇을 더하는 방식
