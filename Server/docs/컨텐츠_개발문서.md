     → 로딩 → 게임(5분) → 결과 → 로비로

| CT-06 | F             | 상호작용         | 주위의 상호작용 오브젝트와 상호작용 (§13)                                                                                                         | 🔄 지금 우클릭 |
| CT-07 | Q             | 스킬             | 캐릭터 고유 스킬 발동 (§9)                                                                                                                        | 🆕             |
| CT-08 | E             | 소비 아이템 사용 | 들고 있는 소비 아이템 사용. 없으면 아무 일도 없음 (§11.7)                                                                                         | 🆕             |
| CT-09 | 마우스 커서   | 시선 방향        | 캐릭터의 시선이 커서 방향으로 바뀌고, 이 방향이 **이동(CT-01)과 공격의 기준**. 상반신은 이동 방향 기준 좌우 90°까지 돎 (연출)               | 🔄             |

### 8.1 무기 규칙

| 번호 | 규칙                                                                                                                                                                                               | 상태    |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| W-01 | 무기는 인벤토리와 별도 칸. **최대 2개** 보유, **삼단봉 포함**                                                                                                                          | 🆕      |
| W-02 | 마우스 휠로 무기 교체 (무기가 하나뿐이면 불가). 고른 무기를 들고 이동                                                                                                                              | 🆕      |
| W-03 | 빈 칸이 있으면 주운 무기가 빈 칸에 들어감. **2칸이 꽉 찼으면 무기1과 바뀜**: 주운 무기가 무기1 칸에 들어가고, 원래 무기1은 **주운 무기가 있던 자리에 놓임** (다른 사람이 주울 수 있음) | 🆕      |
| W-04 | 무기는 스스로 버릴 수 없음                                                                                                                                                                         | 🆕      |
| W-05 | 쓰러지면 삼단봉 외 무기 사라짐                                                                                                                                                                     | 🆕      |
| W-06 | 탄을 다 쓰면 무기가 **자동으로 사라짐** (탄이 정해진 무기). 빈 칸은 W-09에 따라 삼단봉이 채움                                                                                                | 🆕      |

| 공격 범위    | 정면 기준 **60° 부채꼴** (좌우 30°), 반지름 = 탐지 범위 (N-11, 지금 15m). 타겟이 이 부채꼴 안에 있을 때만 사격 |

| 상태         | 🆕                                                                                                                     |

**경비원 범위 (기획 그림 기준)**

```
            시야각 90° (좌우 45°)
          ╱‾‾‾‾‾‾‾‾╲
         ╱ 공격 60°  ╲        반지름 = 탐지 범위 (15m)
 경비원 ●───────────────→ 정면
         ╲ (좌우 30°)╱
          ╲________╱
```

| 범위      | 각도                  | 거리          | 하는 일                                      |
| --------- | --------------------- | ------------- | -------------------------------------------- |
| 탐지 범위 | —                    | 반지름 15m    | 시야각·공격 범위가 닿는 최대 거리           |
| 시야각    | 정면 90° (좌우 45°) | 탐지 범위까지 | 이 안의 플레이어를 발견 → 타겟·추격 (N-11) |
| 공격 범위 | 정면 60° (좌우 30°) | 탐지 범위까지 | 타겟이 이 안에 있으면 사격                   |

- 타겟이 시야각 안이지만 공격 범위 밖(좌우 30°~45°)이면 경비원이 **초당 90°로 돌아서**(N-04) 공격 범위 안에 넣은 뒤 사격. 그래서 옆·뒤로 돌면 사격을 피할 수 있음
